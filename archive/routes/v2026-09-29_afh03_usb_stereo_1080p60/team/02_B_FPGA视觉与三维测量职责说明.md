# B FPGA 视觉与三维测量职责说明

你负责让 FPGA 从双目搜索图找到球，并从左右局部图测出可用于三角化的球心；随后在 RK3576J 上把两只相机的观测变成世界三维轨迹。准备周期为 2026-09-29 至 2026-10-28。[R1]

## FPGA 负责的两个层次

第一层处理 A 送来的左右各 960×540 GRAY8 搜索图。先写 Python 或 C++ 参考，再把 3×3 平滑、同侧帧差、阈值、形态学、连通区域统计做成流水线。每个输出附 `pair_id`、相机侧别、候选框、运动能量与质量计数；保留各级旁路，便于定位噪声、帧尾和边界错误。FPGA DDR3L 保存两只相机的上一帧，片上 RAM 保存行缓存与 FIFO。理论每秒处理 62.21 百万搜索像素；一像素/周期 100 MHz 是综合起点，真实频率由 TD 时序和板上连续流验证。[R1]

第二层处理 A 从同一对 1080p 原图取出的左右各 256×256 局部图。你设计局部阈值或梯度、连通域和球形轮廓筛选、质心/边缘拟合统计，输出左右原图或校正图坐标、质量、有效像素数和 `pair_id`。C 的检测框提供球、手、拍身份，FPGA 的观测承担每对帧的高频球心测量。由你定义局部图坐标到整帧坐标的变换，交给 A/C 共同复核。低运动的最高点继续采用预测窗口与定期重检。

在仿真中逐像素对照参考，覆盖常亮、噪点、移动圆、两个候选、左右错配、图像边缘、输入暂停和跨帧变化。资源报告记录 LUT、DFF、片上 RAM、DSP、DDR 带宽和关键时序；板端再记录候选召回与球心误差。仿真和板端结论分开写。[R1]

## 双目三维怎样得到

固定最终模组、镜头、分辨率和 15～20 cm 基线，拍覆盖发球区域和不同角度的标定板。用 OpenCV `stereoCalibrate` 求左右内参、畸变和相对位姿；再以球台已知点建立 Z 向上的米制世界系。记录标定图、重投影误差与独立球架位置检查。[R2]

同一曝光对中，左右球心经过校正形成视差。简化关系 `Z≈f_px×B/d` 帮助理解：焦距 `f_px` 和基线 `B` 越大，同一距离的视差越明显。正式程序使用完整投影矩阵与三角化计算世界球心，检查左右极线残差、球心质量、视差和正深度。预测点帮助继续搜索；高度和方向来自有效实测观测。

短飞行段拟合轨迹，结合 C 的手框和拍框判断离手与触拍。离手参考球手分离、连续上升和可见间隙；触拍参考邻近球拍和碰前后速度变化。最高点 Z 减离手 Z 得抛球高度；方向用世界初速度与竖直方向的夹角描述。对临界事件保存左右原图、原始 `pair_id`、时间区间、标定版本与质量原因。16 cm 上升规定见 ITTF 规则；辅助提示阈值由三人用量具、误差分布与规则说明评审。[R3]

## 每周交付

- 第 1 周：双目标定装置、独立已知点、世界系定义、搜索和球心软件参考；与 A/C 确定黄金样例。
- 第 2 周：FPGA 双路运动候选、静态球三角化与左右帧对应检查。
- 第 3 周：FPGA 双 ROI 球心、发球三维轨迹、离手与触拍证据。
- 第 4 周：独立球架位置、真实发球误差、FPGA 与软件参考对照，以及异常样例复核。

你牵头量具、标定、空间误差及事件参考；三人共同采集和标注。给 A 的结果包含球心、质量、标定版本和演示字段；给 C 的数据包含真值坐标、图像到世界的定义和困难场景索引。

## 先验证哪些样例

第一组是纯算法图案：静止圆、移动圆、两个圆、亮背景、局部遮挡和行尾跨界。它们使滤波、帧差、形态学、连通域与球心每一级都有期望输出。第二组是左右几何样例：同一个球在已知 1.0、1.3、1.5、2.0 m 位置、画面中间与边缘；用量具记录位置，检查标定和三角化的误差与有效率。第三组是真实发球：为离手、最高点、触拍分别保留人工参考时间区间和左右原图。

统计时把候选漏检、身份识别、球心偏差、左右错误关联、标定误差和事件时间分开。这些误差来源对应不同负责人，便于及时改进。深度随视差变化的公式用于预算；报告的厘米误差只填写独立球架的实测值。对双目共同视场的边界，也记录有效空间范围和球心质量。

评委问 FPGA 作用时，展示同帧搜索图经过 FPGA 各级流水线的结果、ROI 球心与三维位置的对应关系，再比较 FPGA 启用和 RK 软件参考的 CPU、P95 延迟及资源。所有性能对照使用相同输入与相同输出定义。
