# Agent 协作交接包

> 2026-09-20 硬件修订：主板确定为 **MLK-H10-PH1A180**；OV9281 保留为候选传感器，模组、排线和 FSIN 接法未定。优先核对板载 MIPI，不再默认采购 AFH01 子卡。RK3566 暂保留为网口连接的独立计算板候选，RK3588 为升级备选，尚未替换现方案。帧率、同步偏差和推理耗时均为待验证目标。详见 [硬件选型核查](../docs/硬件选型核查.md)。本次不修改 UDP 字节布局、模型输入、坐标系及判罚阈值。


版本：2026-09-20 v1.4。面向参与本项目的各类 Coding Agent、Research Agent、Verification Agent 及纯文本 Agent。

> [!NOTE]
> **Agent 协作变更说明（2026-09-20 v1.4）**：
> 1. **外接智能计算副板定型**：系统正式引入外接 **RK3566 边缘计算板**（四核 Cortex-A55（频率依单板配置），集成 **独立 NPU**），作为 AI 推理与三维判罚引擎。
> 2. **异构全链路架构**：
>    - 前端主导：米联客 **MLK-H10-PH1A180** 开发板（安路 PH1A180 + 1GB DDR3）主导双目 **OV9281 全局快门**（1280×800@120fps）采集、微秒级 FSIN 硬件触发与 128×128 运动局部 ROI 提取；
>    - 物理互联：通过**板载千兆以太网（Gigabit Ethernet / UDP）**向 RK3566 传输轻量 ROI 数据包（总带宽仅约 4.2 MB/s，利用率 3.8%）；
>    - 后端智能：RK3566 NPU 执行专用轻量目标定位模型（成对推理目标 3–5ms，尚未实测），A55 CPU 运行双目稀疏三角化、抛物线拟合与 HDMI 判罚界面。
> 3. **任务卡 H01~H08 重构**：任务卡已全面基于最新的 板载双目 MIPI采集、千兆网 UDP 打包传输、RKNN-Toolkit2 模型量化与 RK3566 几何测量进行更新。

## 1. 当前真实状态

- **用户**：蒲公英，微电子大三；团队共 2 名微电子、1 名人工智能同学。
- **项目**：基于 FPGA-AI 异构视觉的乒乓球发球判罚辅助系统。
- **选题性质**：全国大学生嵌入式芯片与系统设计竞赛（FPGA 赛道 - 安路科技）自主选题。
- **硬件构成**：
  - **前端硬件平台**：米联客 **MLK-H10-PH1A180** 开发板（安路 28nm PH1A180 SFG676，板载 **1GB DDR3** 内存，标准 FMC 接口，板载千兆网口）；
  - **视觉传感器**：双目 **OV9281 全局快门（Global Shutter）** 模组（1280×800@120fps，RAW8/GRAY8，FSIN 硬件同源触发），通过待确认的板载 MIPI 连接方案接入 FPGA；
  - **外接智能协处理器**：**RK3566 边缘计算板**（四核 Cortex-A55，**NPU（性能待实测）**，千兆以太网口，HDMI 输出）。
- **物理互联**：标准 RJ45 双绞线，千兆以太网 UDP 协议。
- **当前已完成**：异构架构定型、带宽与算力预算闭环（ROI 方案将网口占用降至 3.8%）、逐周排期与接口协议 v0.4 制定。
- **当前未完成**：MIPI 引脚约束、FPGA 千兆网 UDP 发送逻辑、RK3566 板端 RKNN 部署、网口接收多线程联调、真实双目标定与实发球测试。

## 2. 谁来承担什么

- **人类模块负责人**：
  - **A 同学（蒲公英/队长）**：FPGA 顶层、板载双目 MIPI OV9281 采集驱动、FSIN 硬件同源触发发生器、1GB DDR3 FDMA 视频流读写控制与比赛统筹。
  - **B 同学（微电子同学）**：FPGA 图像差分预处理流水线、双目 128×128 运动 ROI 裁剪逻辑、千兆以太网 UDP 数据包封装与推流模块。
  - **C 同学（AI 同学）**：专用小目标定位模型设计与训练、通过 RKNN-Toolkit2 导出 RK3566 专属 INT8 模型、RK3566 接收端程序编写、双目稀疏立体三角化、抛物线拟合与 HDMI 图形界面。
- **Agent 协作原则**：
  - **Coding Agent**：负责具体的 Verilog RTL 模块编写（FSIN 发生器、差分处理、UDP 打包）、C++ 接收解包线程、RKNN 推理包装与拟合算法实现。
  - **Research Agent**：负责检索米联客 板载 MIPI 配套连接方案（待确认） 官方原理图、安路 TD（与该板例程匹配的版本） 约束语法、瑞芯微 RKNN-Toolkit2 转换配置文档。
  - **Verification Agent**：负责 Wireshark 抓包日志校验、RK3566 NPU 推理延迟统计、已知高度真值还原对比。

## 5. 首批任务卡（基于 FPGA-RK3566 异构架构）

### H01：MLK-H10-PH1A180 平台与 板载双目 MIPI OV9281 引脚矩阵
- **责任人**：A 同学（蒲公英）+ Research Agent；优先级 P0，截止 9/21。
- **输入**：米联客 MLK-H10-PH1A180 原理图、板载 MIPI 接口手册及必要转接件资料、OV9281 模组引脚定义。
- **输出**：双路 MIPI D-PHY 差分线、I2C 控制引脚、**FSIN 同步触发引脚**在 PH1A180 上的引脚号、电平标准与约束表。
- **验收**：每个引脚有原理图明确出处；电平标准（1.8V/3.3V）严格匹配。

### H02：双目 120fps 全局快门与 FSIN 硬件触发仿真
- **责任人**：A 同学 + Coding Agent；截止 9/25。
- **输入**：《接口与验收契约 v0.4》、1280×800@120fps 像素时钟与行场时序参数。
- **输出**：Verilog FSIN 硬件脉冲发生器模块（目标 120Hz，脉宽/极性按模组规格确认）、双路立体图像 Testbench。
- **验收**：仿真中两路虚拟相机由 FSIN 同步启动，曝光起始点偏差 < 100ns，成对打上相同 `pair_id`。

### H03：双目稀疏立体三角化与抛物线拟合 C++ 实现
- **责任人**：C 同学 + Coding Agent；截止 9/27。
- **输入**：双目标定矩阵参数、带已知高度真值的抛球三维合成轨迹。
- **输出**：C++ 编写的立体三角化、离手状态机、二次抛物线加权最小二乘拟合函数。
- **验收**：在无噪合成数据上完全复原真实高度（误差 < 0.5mm）；单次解算耗时在 PC/ARM 上 < 0.5ms。

### H04：FPGA 运动差分、ROI 提取与千兆网 UDP 打包 RTL
- **责任人**：B 同学 + Coding Agent；截止 10/2。
- **输入**：1280×800 灰度流、128×128 局部 ROI 规范、《接口契约 v0.4》UDP 数据包结构。
- **输出**：相邻帧差分运动检测模块、128×128 裁剪逻辑、UDP 数据包组装 RTL 与 Testbench。
- **验收**：仿真中正确提取出含有运动小球的 128×128 区域，输出标准的 16448B UDP 包，包头坐标与时间戳正确无误。

### H05：专用小目标 CNN 训练与 RK3566 NPU（性能待实测） RKNN 部署
- **责任人**：C 同学 + Coding Agent；截止 10/2。
- **输入**：乒乓球局部图像样本、RKNN-Toolkit2 工具链。
- **输出**：Tiny-BallNet 模型（参数量 < 50k）、量化转换脚本、导出的 `.rknn` 模型文件及板端基准测试脚本。
- **验收**：独立测试集可见球召回率 ≥ 95%，球心 MAE < 0.3 px；RK3566 板端推理耗时 $\le 2.5\text{ ms}$ / 张。

### H06：FPGA 与 RK3566 千兆以太网联调及网络抖动测试
- **责任人**：A 同学 + B 同学 + C 同学；从 10/3 开始派发。
- **输入**：FPGA 顶层 Bitstream、网线直连、RK3566 Linux 接收端多线程程序。
- **输出**：网络连通性与吞吐测试报告、Wireshark 抓包日志、丢包与坏帧计数器。
- **验收**：120fps 下成对 ROI 稳定推流（约 4.2 MB/s），连续运行 1h 无未解释丢包或乱序，端到端网络传输耗时 < 1.0ms。

### H07：RK3566 HDMI 判罚主界面开发
- **责任人**：C 同学 + Coding Agent；截止 10/16。
- **输入**：RK3566 实时三维测量结果流、视频缓冲帧。
- **输出**：基于 Qt 或 OpenCV 的裁判辅助判罚 GUI 程序（显示实时画面、三维轨迹、测量数值及大字判定状态）。
- **验收**：界面刷新流畅（≥ 60fps），不阻塞网络接收线程，支持慢动作历史回放。

### H08：全系统 100 次独立发球验收与技术报告生成
- **责任人**：全队 + 验证 Agent；截止 10/23。
- **输入**：异构闭环整机、已知高度物理量具基准、100 次发球实录。
- **输出**：误差统计 CSV 数据、柱状分布图、失败案例与原因分析、技术报告初稿。
- **验收**：受控条件下 MAE ≤ 10mm，P95 ≤ 20mm；数据真实可靠，可完全追溯至原始日志。
