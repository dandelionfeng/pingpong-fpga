# 乒乓球发球辅助系统：硬件选型与采购参考清单

更新：2026-09-21。主板固定 MLK-H10-PH1A180，AI 板固定瑞莎 Radxa ZERO 3E，摄像头选用微雪 OV9281（120°广角款）。本表仅列出需要正式采购的核心电子元器件、板卡、专用电源与调试模块；通用线缆、数据线、结构支架、补光灯、标定板及实验室通用仪器均已剔除，使用现有物资。

连接：双 OV9281 → H10 板载 MIPI → FPGA 同步、采集与 ROI → 千兆网 UDP → ZERO 3E 推理、几何计算与显示。

## 一、核心主板与视觉感知前端

| 器件 / 方案 | 数量 | 采购要求 |
| --- | --- | --- |
| MLK-H10-PH1A180 | 1套 | 已定型号；确认底板版本、原理图、MIPI接收例程、引脚约束、DDR/网口例程及IP授权。 |
| 微雪 OV9281 摄像头（120°广角款） | 2块 | 视觉采集器件。黑白全局快门、1280×800@120fps、手动对焦锁紧；120°广角透镜适合近距离大范围视野覆盖。购买前确认FSIN外触发引出焊盘、RAW格式支持及120fps模式配置。 |

主板 MLK-H10-PH1A180 自带板载 2×4 Lane MIPI 接口，不再采购任何额外 FMC 转接板（如 FMC-AFH01 或 FMC-VID005）；通用连接排线与同步跳线不单独列入采购项。官方参考：[微雪 Wiki 资料中心](https://www.waveshare.net/wiki/OV9281-110_Camera)、[微雪官网产品主页](https://www.waveshare.com/product/ov9281-110-camera.htm)、[H10开发板](https://www.uisrc.com/t-6256.html)。

## 二、AI模块：固定瑞莎 ZERO 3E

| 器件 | 数量 | 规格与用途 |
| --- | --- | --- |
| Radxa ZERO 3E，建议4GB版 | 1块 | RK3566、板载NPU、千兆RJ45、Micro-HDMI；接收FPGA ROI并做RKNN推理、几何与显示。摄像头仍接FPGA。 |
| 匹配的软件环境 | 1套 | Linux镜像、NPU驱动、RKNN Runtime和模型版本必须匹配；先跑官方示例，再测实际模型延迟。标称TOPS不等于帧率保证。 |

订单写清内存版本；按microSD启动准备，不默认包含eMMC。ZERO 3E无板载Wi-Fi，开发时安排有线联网。官方：[产品页](https://radxa.com/products/zeros/zero3e/)、[准备工作](https://docs.radxa.com/en/zero/zero3/getting-started/preparation)、[硬件接口](https://docs.radxa.com/en/zero/zero3/hardware-design/hardware-interface)、[RKNN工具](https://github.com/airockchip/rknn-toolkit2)。

## 三、电源、散热与存储

| 配件 | 数量 | 规格 / 必要性 |
| --- | --- | --- |
| H10原厂电源适配器 | 1套 | 必需，先确认套餐是否含；电压、电流、插头和极性按实际板卡原厂要求，不与瑞莎混用。 |
| ZERO 3E电源适配器 | 1套 | 必需，建议稳定5V/3A；官方最低建议5V/2A。接供电/OTG口，仅5V，不能接12V或强制升压。 |
| ZERO 3E散热片与导热垫 | 1套 | 建议必备，选匹配板卡尺寸的套件，避免短接元件。 |
| 5V小风扇及固定件 | 1套 | 预留采购，持续推理测温后决定安装。由额定电源供电，不用GPIO信号脚直接驱动；先核对接口。 |
| FPGA散热套件 | 1套 | 先清点随板散热片/风扇，缺少时向原厂补齐匹配套件。 |
| 品牌microSD存储卡 | 1张 | 必需，建议32GB或64GB；另备1张可选，不默认随板附送。 |
