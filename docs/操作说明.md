# 操作说明

1. 双击根目录的发球测量系统.exe。
2. 保持 RK—FPGA PCIe 连接。需要下载时，打开下载工具，将 app/fpga 内的原 bit 流下载至 FPGA SRAM。
3. J4 连接 PC，点“J4 检查与部署”。
4. 相机接 RK，J3 接 PC。打开现场终端，选择 COM 口后连接。串口参数为 1500000 baud、8N1；进入空闲 Shell 后自动设置内核日志等级。
5. 相机使用 /dev/video73，自动曝光。点“开始录制”，每轮进行一次发球。录制后 RK 自动逐对分析并保存测量结果。“正常提前停录”会保存已采集帧并继续分析。
6. 等待 RECORDING_SAVED，记下 RK 结果名。J4 接回 PC，在“取回 RK 结果”输入该名称。
7. 在测试记录中查看左右目视频、轨迹、抛球参数和有效/估算状态。默认回放速度为 0.5 倍。

展示数据按 data/index.json 重编号为 serve_01–serve_06。取回功能保留 RK 原结果名到本地展示编号的映射；本地编号冲突时使用 rk_ 前缀。

首页三维演示显示近竖直上抛和回落过程。拖拽时手动旋转，松开后自动旋转；滚轮缩放，空格暂停，R 复位。演示使用示意轨迹，测试记录的回放读取对应实测数据。

单对图像延迟以毫秒显示，统计文件帧入队至在线结果输出并包含排队。整段分析、最终测量、取回及回放生成以秒显示。旧记录缺失的阶段计时显示“未记录”。

软件日志保存在 logs。退出前等待当前采集或处理结束，再点击“退出工作台”。
