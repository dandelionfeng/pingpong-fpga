# OV9281 USB 双目模组选型核对

更新：2026-10-04。当前技术方案选用 HBVCAM-W2307-2 V11 系列的 **72°、3.6 mm 手动调焦双 OV9281 USB3 模组**，目标 YUY2 左右拼接 2560×720@60 fps、每眼 1280×720，支架光心基线 150～200 mm。依据为[当前技术路线](../plans/current/usb-stereo/技术路线_AFH03与USB同步双目测量方案.md)和最新 Word；实际 SKU、PCB/固件、视场口径及目标模式仍需所购版本的资料和实物记录。

## 与当前链路对应的理论数据量

计算使用十进制 MB/s，只计纯图像载荷，未含协议、队列和缓存开销。

| 数据 | 每对大小 | 60 对/秒载荷 |
| --- | ---: | ---: |
| 2560×720 YUY2 拼接帧 | 3,686,400 字节 | 221.184 MB/s |
| 两眼 1280×720 GRAY8 | 1,843,200 字节 | 110.592 MB/s |
| 两眼 640×360 GRAY8 搜索图，H2C | 460,800 字节 | 27.648 MB/s |
| 两眼 1 bit Mask，每眼行 80 字节，C2H | 57,600 字节 | 3.456 MB/s |

FPGA 处理搜索图并返回 Mask；CPU 从同帧原图取 256×256 ROI，求球心、三维与事件。此处理论预算沿用当前技术路线，真实 USB/PCIe 吞吐和调度延迟另测。旧 100 fps 模式与双 ROI 传给 FPGA 的预算保存在历史文件。

## 采购和到货记录入口

订单注明 72°、3.6 mm 手动调焦、双 OV9281、USB3/UVC 以及对应 SKU/PCB/固件版本，留存该版本的同步、曝光和 YUY2 模式说明。固定刚性支架和光心基线，手动调焦锁定后进行最终标定；线缆与主机模式按 AFH03 资料核对。

到货先在 PC 记录相机模式、控制项和原始帧，再在 AFH03 J4 USB3 OTG0 验枚举、供电及与 PCIe1 并发。Linux 入口为 `v4l2-ctl --list-formats-ext`、`--list-ctrls-menus` 和 `lsusb -t`；设备节点、控制单位和驱动能力以实物为准。[待确认项](实施前待确认项.md)及[PC 到部署清单](PC算法闭环与部署验收.md)承接标定、同步和整机检查。
