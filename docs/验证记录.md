## 源码包启动修复

源码包 EXE 在缺少 `runtime/python/python.exe` 时改用自身携带的 Python 解释器执行外部 `app/pc/gui_server.py`。源码包自检覆盖入口定位、源码审核运行时、本地服务、首页、版本接口和正常关闭；完整运行包仍优先使用原离线运行时，并继续覆盖六组记录与六份 MP4 Range 读取。两类报告以 `mode=source-embedded` 和 `mode=complete` 区分。

本修复只涉及 Windows 启动器、构建脚本和说明，不修改 `app/version.json`、模型、标定、世界坐标、检测阈值、运动学阈值、实测数据或板端程序，也不构成新的 FPGA/NPU、硬件或物理精度验证。

2026-11-01 实测的新 EXE SHA-256 为 `6db248249b5485adb38d467d12649370990653eebbba91022b56bf2351929c2b`。纯源码结构自检退出码为0，普通 `--no-open` 启动后首页和健康接口可访问，关闭后无残留进程。将同一 EXE 放入完整运行包结构后，自检退出码为0，读取6组记录、6份视频 Range 和1677对图像，`raw_results_unchanged=true`。
