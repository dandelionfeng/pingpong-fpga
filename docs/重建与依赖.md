# 重建与依赖

Windows EXE 构建环境为 Python 3.13、PyInstaller 6.22.3 与 Pillow 12.3.0。tools/build_windows.py 生成根目录的发球测量系统.exe；app、runtime、data、release.json 与之同目录运行。

PC 运行环境使用随包 Python 3.13、OpenCV 5.0.0、NumPy 2.5.2、pySerial 3.5 和 imageio-ffmpeg 0.6.0。runtime/python/python313._pth 将模块路径限定在本安装目录。软件日志位于 logs。

RK 基线依赖板端 Python 3、RKNN runtime、OpenCV 4.13.0、现有 PCIe 驱动和 FPGA bit 流。runtime/board-dependencies 包含已有离线重建材料；app/tools/rk-wheels 为 Python 板端依赖。部署包为 app/dist/quick-field-runtime.tar.gz，由 payload-sha256.json 校验。

原生源码入口为 source/native/CMakeLists.txt。RK 环境中可指定已安装依赖后构建：

```sh
cmake -S source/native -B build/rk -DCMAKE_BUILD_TYPE=Release \
  -DRKNN_INCLUDE_DIR=/userdata/codex-full-project-20261017/private-sdk \
  -DOpenCV_DIR=/userdata/codex-full-project-20261017/opencv/lib/cmake/opencv4 \
  -DFETCHCONTENT_SOURCE_DIR_JSON=/userdata/codex-full-project-20261017/json-source
cmake --build build/rk --target motion7_chain_kinematic -j1
```

现有 ARM 可执行文件是已验证的运行基线，哈希见 model-sha256.json。包内重排的源码构建配置按对应源文件组织；本次 PC 整理未在 RK 重新编译。

FPGA 源码在 hardware/rtl，当前工程在 hardware/project，已验证 bit 流在 app/fpga。厂商 IP 与私有 SDK 随本地运行包管理。
