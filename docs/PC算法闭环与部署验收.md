# 无硬件阶段算法闭环与部署验收

2026-10-04 修订。本文是新版技术路线和三人分工的执行清单，当前内容为待实施方案。它规定到货前怎样证明代码正确、怎样交接，到货后怎样增加实机证据；本次文档修订没有执行模型训练、RTL 仿真或算法测试。

## 1 对原无硬件方案的判断

文件替代采集、整数参考对照 RTL、PC 完成局部测量及三维事件、提前训练导出模型的思路适合本项目。需要补齐四处：统一可迁移的 C++ 核心；按层次验证输入而不把单目图当真实双目；将手和球拍的观测加入事件测试；在 PC 阶段就验证异步、背压和引用生命周期。

到货前可以完成所有主要算法模块、受控输入的整流程、真实公开画面的三类 PC 模型及导出工具链。没有最终相机，目标域模型效果和真实米制测量准确率仍待确认；没有 AFH03，DDR3L、双向 DMA、RGA、NPU Runtime 和实时性能仍待实机验收。使用检测框回放的全流程只验下游算法，实际模型模式另列结果。

## 2 共用架构与实现入口

正式架构沿用 72°、3.6 mm 双 OV9281、2560×720 YUY2@60、RK3576J、PH1A90SEG324 和 PCIe1。搜索图为每眼 640×360 GRAY8，FPGA 返回运动 Mask；256×256 ROI 在原图缓存中裁切，球心、几何与事件在 CPU 中实现。世界系 X 横向、Y 球台纵向、Z 向上，单位米。

PC 文件 → Y提取/左右拆分 → 8对原图缓存和2×2缩图 → CPU七级整数运动前端 → 双Mask → 候选/原图ROI/球心 → 点校正/三角测量/世界变换 → Kalman → 三个关键点。PC检测模型从原图上下文异步产生球、手和球拍框；在最高点附近，即使Mask为空也沿预测ROI重新测量。

核心选 C++17、CMake、OpenCV；先实现无界面运行和结果导出，再接 Qt 回放。Python 用于独立真值、测试数据、评分及模型训练，正式算法避免到货后整体重写。Windows 验算法；PC Linux 验构建和 Toolkit2 支持环境，WSL2 可作为开发选择，USB 接入按实际环境单独核实。

以下是拟实现的逻辑接口和目录，不代表现有功能已完成；落实时由负责人提交各自任务分支并评审。

## 3 输入包和真值隔离

所有样例使用 manifest 记录来源、许可、校验和、宽高、像素格式、stride、眼别、pair_id、采样时间、场次和配置版本。时间单位统一为 ns，算法 dt 取采样时间，wall-clock 排队时间另存；合成时间明确标 synthetic。测试程序只读 inputs 和运行配置，truth 在评分过程单独加载，禁止用真值球心、事件时刻或测试标签引导被测算法。

| 数据层次 | 输入 | 能验证的部分 | 负责与交叉检查 |
| --- | --- | --- | --- |
| 像素黄金样例 | YUY2字节、行填充、单点/棋盘/边缘对象、双路序列 | 拆图、缩图、整数阶段、打包、RTL流控 | A生成，B独立复核 |
| 标定练习 | OpenCV成对棋盘图与多姿态合成棋盘 | 角点、标定、配置保存/加载及留出图重投影 | B实现，C评分；公开图尺度未知时按方格单位 |
| 几何真值 | 独立投影的左右观测点及两眼渲染图 | 畸变、R1逆旋转、世界变换、噪声/错配拒收 | B生成，A/C独立核对 |
| 事件观测 | 持球、球运动和hand/racket框，含迟到/缺失；独立真值区间 | 离手、顶点、触拍、证据不足与取消发球 | C组织，B实现，A回放 |
| 真实公开图像 | 有许可的乒乓球发球图像，补齐三类标签并按场次隔离 | 三类模型、局部球心、PT/ONNX和2D事件证据 | C组织，三人补标 |
| 到货后真实输入 | 最终相机原始Y、真实标定、独立位置/事件参考 | 目标域准确率、同步及完整整机性能 | 三人按正式清单验收 |

单目图或复制/平移后的单目图可用来测格式与2D模块，不能据此声明真实双目标定或三维准确率。合成相机必须包含非零旋转和畸变，左右图由两个相机分别投影；只用平行、无畸变特例会漏掉坐标方向错误。合成训练和合成测试也分开场景、轨迹、背景及随机种子。

## 4 兼容影响与共同语义草案

保留现行 72°路线的尺寸、640×640 gray3 模型输入、世界坐标、掩膜主路径和总调用预算。本版只新增可替换后端与可复现测试。新增错误状态、reference_id、来源标记和帧引用影响 A 的缓存/接收、B 的帧差/测量、C 的异步框；三人于 10 月 5 日用同一包评审，当前未冻结二进制结构或判罚阈值。

拟评审起点：2×2平均为(四像素和+2)>>2；Gaussian为3×3核[1,2,1]外积、(S+8)>>4；前景判据 abs(current-prev)>12；四级形态学为腐蚀、膨胀、膨胀、腐蚀，每一级复制邻边。测试应包含差值11/12/13和取整临界值。打包位序由A/B评审后写入一字节8像素的黄金向量，不能仅靠打包器和解包器同时犯错而“自洽通过”。

左右眼独立前帧，首帧建立参考并输出零Mask、reference_valid=false。完整成功帧才更新参考，记录 reference_id；跳帧后与同眼最近完整参与处理的图比较，算法使用实际 dt。截断任务、超时、复位和配置切换须明确是否保留/清空参考。下游不得将未初始化或失败结果当有效零运动观测。

每个测量结果保留 pair_id、采样时间、标定/参数版本、左右球心及质量、观测/滤波/预测类型。搜索中心到原图为 u=2u_s+0.5，框边界按覆盖范围处理；ROI保留原点、有效区域和补齐。三角测量后先 Xc=R1ᵀXrect，再 Xw=Rcwᵀ(Xc−tcw)，其中 Rcw/tcw 是 solvePnP 世界到左相机变换。

检测结果保留 source_pair_id、eye、ROI原点、比例/补边、模型版本和完成时间。旧帧框不得直接叠到当前帧；可对原帧身份归档后用显式预测影响当前搜索。8对原图在60fps仅约133ms：为推理持有必要裁块或引用，设独立容量/过期策略，禁止无限增长。20～30次/秒是全部检测任务的调度目标，左眼优先，右眼歧义共享预算；PC mock 调度不能证明 NPU 吞吐。
