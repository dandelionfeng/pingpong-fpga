# 手部检测数据集调研（乒乓球转播/全景远景、小手）

- 调研日期：2026-10-15
- 目标场景：1920×1080 全景机位，球员全身可见，手部约 30–90 px；**必须**有原生人工标注 bbox；**不允许**从关键点反推 bbox。
- 调研方式：仅使用官方项目页 / 官方仓库 README / 原始论文（arXiv、CVF、ar5iv）。凡未能证实的一律标注 `UNCONFIRMED`，不做推测。
- 结论速览：**没有任何一个公开数据集是"体育转播 + 小手 + 原生人工框 + 宽松许可"四者兼具的。** 最接近的是 TV-Hand 与 ContactHands（原生人工四边形框、尺度匹配），但两者许可都不明确/受限；COCO-Hand 与 COCO-WholeBody 的手框**是从关键点推导的**，按项目约束必须排除。

## 2. 逐数据集详情

### 2.1 TV-Hand —— 首选

- 来源：[Hand-CNN 项目页（Stony Brook）](http://vision.cs.stonybrook.edu/~supreeth/)；论文 *Contextual Attention for Hand Detection in the Wild*, ICCV 2019（[arXiv:1904.04882](https://ar5iv.labs.arxiv.org/html/1904.04882)）
- 下载：<http://vision.cs.stonybrook.edu/~supreeth/TV-Hand.zip>（2.3 GB，**直链，无需注册**）
- **许可：UNCONFIRMED。** 该页面通读后**没有任何**许可/版权声明（只有数据集链接、代码、论文、引用）。同站点同作者的 BodyHands/ContactHands 页面**有**专有版权声明，而本页没有——不能据此推定宽松。用于任何非研究用途前必须联系作者。
- **bbox：✅ 原生人工标注。** 三名标注员绘制**四边形（非轴对齐）紧致框**，并标出四边形中连向手腕/手臂的那条边。**不是**从关键点推导。使用时需自行把四边形转成外接 AABB——这是对**已有人工框**的确定性几何换算，不违反"不得由关键点推导"的约束。
- 数量：9,498 帧（train 4,853 / val 1,618 / test 3,027），共 **8,646 个手框**（4,085 / 1,362 / 3,199）。约一半图像**无手**；单图最多 9 只手。
- 场景：**✅ 全景。** 取自 ActionThread 的电视剧/电影帧，多机位、多尺度、自然遮挡与截断、含运动模糊。图像高度统一归一化为 **360 px**，宽度按原始宽高比变化。
- **手部尺度（关键量化依据）：** 标注门槛为"可见手部面积 > 100 px²"，且**约 50% 的手面积 ≤ 1000 px²**（≈33×33 px）。按 360p→1080p 的 3 倍线性换算，等效为 **1080p 下约 30–100 px 的线性尺寸**——与目标 30–90 px 区间高度吻合。这是所有候选里尺度匹配最好、且有论文原文量化支撑的一个。
- 风险：许可未声明；仅 8,646 个框，规模偏小；源分辨率低（360p 高），外观细节有限，建议训练时按相对尺度做多尺度增强而非直接放大。

### 2.2 ContactHands —— 次选（规模最大的人工框小手段）

- 来源：[项目页](http://vision.cs.stonybrook.edu/~supreeth/ContactHands_data_website/)；[代码仓库](https://github.com/cvlab-stonybrook/ContactHands)；论文 *Detecting Hands and Recognizing Physical Contact in the Wild*, NeurIPS 2020（[ar5iv](https://ar5iv.labs.arxiv.org/html/2010.09676)）
- 下载：<https://public.vinai.io/ContactHands.zip>（4.5 GB）或同页 Google Drive 链接。**直链，无需注册。**
- **许可：⚠️ 数据为研究用途/专有。** 项目页 `Copyright and Disclaimer` 原文：*"all copyright and all rights therein are maintained by and remained proprietary property of the authors and/or the copyright holders."* 注意：仓库根目录 `LICENSE` 是 **MIT**（`Copyright (c) 2020 CVLab@StonyBrook`），但 MIT 正文限定于 *"this software and associated documentation files"*——**只覆盖代码，不覆盖数据**。任何非研究用途必须先取得作者书面许可。
- **bbox：✅ 原生人工四边形框。** 多名标注员绘制"包含尽可能多手部像素"的紧致四边形，每批由第二位标注员复核，接触状态抽检错误率 <2%。**不是**关键点推导。
- 数量：**21,637 张图像**，**58,165 个手实例**（train 18,877 图 / 52,050 手；test 1,629 图 / 5,983 手）。
  - 注：页面写 test 手数 5,893，论文正文一处写 5,983，存在轻微不一致 → 以实际标注文件为准。
- 场景：**✅ 全景非受限。** 来源为 MS COCO、PASCAL VOC、Flickr（仅取有版权许可的照片）、Oxford Hand、TV-Hand。多人、遮挡、截断场景。
- **手部尺度（关键量化依据）：** 论文明确规定标注门槛为 **"框的最短边 > min(H,W)/30"**，并明确要求标注截断/遮挡手（只要可见面积过阈值）。对 1920×1080 即 **≥36 px**。也就是说该数据集**在设计上就保证包含小尺度手**。这是除 TV-Hand 外唯一有明确小尺度保证的候选。
- 额外价值：每只手带 4 个多标签接触状态（No-/Self-/Other-Person-/Object-Contact），可作辅助任务。

### 2.3 BodyHands —— 次选（与 ContactHands 同源，额外提供人体框与手-体关联）

- 来源：[项目页](http://vision.cs.stonybrook.edu/~supreeth/BodyHands/)；[代码仓库](https://github.com/cvlab-stonybrook/BodyHands)；论文 *Whose Hands Are These? Hand Detection and Hand-Body Association in the Wild*, CVPR 2022
- 下载：<http://vision.cs.stonybrook.edu/~supreeth/BodyHands/BodyHands.zip>（**4.6 GB，直链，无需注册**）
- **许可：⚠️ 同 ContactHands。** 项目页有相同的专有版权声明；仓库 `LICENSE` 为 MIT（`Copyright (c) 2022 CVLab@StonyBrook`），同样只覆盖软件。
- **bbox：✅ 原生人工四边形手框 + 人体框 + 手↔人体对应关系**（同色同编号）。数据集基于 ContactHands 构建。
- 数量：BodyHands 自身的精确图像/框数 **UNCONFIRMED**（项目页只给了 zip 大小，未给计数）。按"基于 ContactHands"推断应与 21,637 图 / 58,165 手同量级，但**未经证实，不要引用具体数字**。
- 场景：✅ 全景非受限，多人、重叠、遮挡。
- 尺度：继承 ContactHands 的 min(H,W)/30 门槛。
- 对本项目的额外价值：手-体关联可直接用于"这只手属于哪位球员"的下游逻辑。

### 2.4 HaGRID / HaGRIDv2 —— 仅建议作预训练

- 来源：[官方仓库](https://github.com/hukenovs/hagrid)；HaGRID WACV 2024；HaGRIDv2 [arXiv:2412.01508](https://arxiv.org/abs/2412.01508)
- 下载：SberCloud 直链（按手势分卷），例如
  - 标注：<https://rndml-team-cv.obs.ru-moscow-1.hc.sbercloud.ru/datasets/hagrid_v2/annotations_with_landmarks/annotations.zip>
  - 512px 轻量版：<https://rndml-team-cv.obs.ru-moscow-1.hc.sbercloud.ru/datasets/hagrid_v2/hagridv2_512.zip>（119.4 GB）
  - **直链，无需注册/登录。** 完整版 1.5 TB。
- **许可：⚠️ CC-BY-SA-4.0 的"变体"。** README 原文：*"This work is licensed under a variant of Creative Commons Attribution-ShareAlike 4.0 International License"*，并指向 [license/en_us.pdf](https://github.com/hukenovs/hagrid/blob/master/license/en_us.pdf)。**该 PDF 我无法解析（以 octet-stream 返回）→ 具体条款 UNCONFIRMED。** 两点必须注意：(1) 是"变体"而非标准 CC-BY-SA-4.0；(2) **ShareAlike 传染性**对"训练出的权重是否算衍生作品"存在法律争议。**使用前必须逐字读完该 PDF。** 另注意：arXiv 上的论文本身是 CC-BY-4.0，但那是论文许可，不是数据集许可。
- **bbox：✅ 原生人工框。** COCO 格式归一化 `[x, y, w, h]`，每图 1–2 只手（双手势有 `united_bbox`）。另有 MediaPipe 自动标注的 21 点关键点，但**关键点是附加项，框是独立的人工标注**——符合约束。
- 数量：**1,086,158 张 FullHD 图**，**1,504,133 个框**（train 1,135,327 / val 139,414 / test 229,392），65,977 个不同人物，33 类手势 + `no_gesture`。HaGRID v2.0（2023）为 554,800 图 / 723 GB。
- 场景：⚠️ 1920×1080 全身/半身单人照，被摄者距相机 0.5–4 m。**不是**宽场多人的赛场视角。
- **手部尺度：❌ 明显过大。** 以 README 自带示例标注为准：`bbox = [0.0694, 0.3104, 0.2667, 0.2641]` → 0.2667×1920 ≈ **512 px 宽**、0.2641×1080 ≈ **285 px 高**。即便在 4 m 端，手也远大于 90 px。**尺度不匹配是本数据集的主要短板。**
- 额外价值：官方提供在 HaGRIDv2 上训练的**手检测模型**（YOLOv10x mAP 88.8 / YOLOv10n mAP 87.9），可作为基线或伪标签工具。`no_gesture` 类（203,200 个框）可作困难负样本。

### 2.5 100DOH（100 Days of Hands）

- 来源：[官方仓库](https://github.com/ddshan/hand_object_detector)；论文 *Understanding Human Hands in Contact at Internet Scale*, CVPR 2020（[arXiv:2006.06669](https://arxiv.org/abs/2006.06669)，[CVF 页面](https://www.openaccess.thecvf.com/content_CVPR_2020/html/Shan_Understanding_Human_Hands_in_Contact_at_Internet_Scale_CVPR_2020_paper.html)）
- 下载：仓库 README 指向 <https://fouheylab.eecs.umich.edu/~dandans/projects/100DOH/downloads/pascal_voc_format.zip>（PASCAL-VOC XML 格式）。**⚠️ 官方项目页 `http://fouheylab.eecs.umich.edu/~dandans/projects/100DOH/` 我多次尝试均无法访问**（该主机重定向到实验室根路径且抓取失败）→ **是否需要注册/登录、完整下载清单：UNCONFIRMED。**
- **许可：❌ UNCONFIRMED，且有非宽松迹象。** 仓库 README **完全没有许可章节**。第三方大规模审计（*Bridging the Data Provenance Gap Across Text, Speech, and Video*, [arXiv:2412.17847](https://arxiv.org/html/2412.17847v1)）在其数据集许可表中将 **100DOH 的许可标注为 "Custom"**。此外源帧来自 YouTube，受 YouTube ToS 及源内容限制（该审计指出视频数据 99% 的体量在来源层面带非商用限制）。
- **bbox：✅ 原生人工手框。** 仓库 README 说明其输出为 `hand_dets: boxes(4), score(1), state(1), offset_vector(3), left/right(1)`，训练数据为 PASCAL-VOC XML `Annotations/`。InterTracker（[arXiv:2308.03061](https://ar5iv.labs.arxiv.org/html/2308.03061)）亦确认：*"The annotations in this dataset include hands' bounding boxes, hand sides, hand contact states, and objects' bounding boxes."* 手框、左右手、接触状态为人工标注；**物体框为检测器产生后人工校验**（注意这一区别）。
- 数量：**约 100K 帧**已标注（论文摘要：*"a large-scale dataset of hands in contact with objects consisting of 131 days of footage as well as a 100K annotated hand-contact video frame dataset"*）。**总手框数 UNCONFIRMED**（常见引用为约 240 万手+物框，本次未能在原始出处证实 → 不要引用）。
- 场景：⚠️ 第三人称互联网/YouTube 日常手物交互视频（11 类：DIY、家具、学习、维修、打包、拼图、园艺、桌游、家务、饮用、食物）。是全景，但镜头通常聚焦手部/桌面，手是画面主体。
- 手部尺度：**UNCONFIRMED**（未找到量化分布），但按镜头取景判断手偏大（应为 100–300 px 量级），**不匹配**目标 30–90 px。
- 另提供 ego 子集（Epic-Kitchens / EGTEA / CharadesEgo 帧名列表），属第一人称。

### 2.6 COCO-Hand / COCO-Hand-S —— 排除（框由关键点推导）

- 来源：同 [Hand-CNN 项目页](http://vision.cs.stonybrook.edu/~supreeth/)；ICCV 2019 论文。
- 下载：<http://vision.cs.stonybrook.edu/~supreeth/COCO-Hand.zip>（1.2 GB，直链）。
- 许可：**UNCONFIRMED**（页面无声明）。图像来自 MS COCO，需另行遵守 COCO/Flickr 原始条款。
- ❌ **bbox：由关键点推导——直接违反项目硬约束。** 论文原文说明：对 82,783 张 COCO 图运行 Simon et al. 2017 的**手部关键点检测器**，得到 161,815 个手检测，再用保守启发式筛选（预测手腕与真值手腕距离 / 框长 > 0.2 则丢弃），并取"与预测手方向对齐的最小外接矩形"作为框。最终 COCO-Hand = 26,499 图 / 45,671 手；COCO-Hand-S（人工复核子集）= 4,534 图 / 10,845 手。
- ❌ 额外缺陷：漏检的手被**用黑色圆形掩码涂掉**（圆心=真值手腕，半径=腕-肘距离），图像存在黑色斑点，不适合直接训练。
- **"COCO-Hand-Big"：UNCONFIRMED。** 本次检索未能证实存在官方命名为 COCO-Hand-Big 的数据集（只证实了 COCO-Hand 与 COCO-Hand-S）。若团队计划中的是该名字，请重新提供出处。
- 结论：即使团队愿意放宽"不得由关键点推导"的约束，也还需处理黑色掩码与图像版权问题。**建议直接放弃。**

### 2.8 FreiHAND —— 排除

- 来源：[官方数据集页](https://lmb.informatik.uni-freiburg.de/resources/datasets/FreihandDataset.en.html)；ICCV 2019。
- 下载：`FreiHAND_pub_v2.zip`（3.7 GB）+ `FreiHAND_pub_v2_eval.zip`（724 MB），直链。
- **许可：❌ 研究用途，禁止商用。** 原文：*"This dataset is provided for research purposes only and without any warranty. Any commercial use is prohibited."*
- bbox：❌ **无手部边界框。** 提供 224×224 RGB 图、手部分割掩码、21 点 3D 关键点、MANO 形状参数、内参、手部尺度。
- 场景：❌ 全部为 **224×224 裁剪图**（绿幕抠图后处理）。
- 结论：与现有 Ultralytics `hand-keypoints` 属同一类（特写裁剪、无框、非商用），**无新增价值，排除。**

### 2.9 Something-Else —— 排除（两个同名对象）

- **(a) Something-Else（Materzynska et al., CVPR 2020）**：[arXiv:1912.09930](https://ar5iv.labs.arxiv.org/html/1912.09930)，项目页 <https://joaanna.github.io/something_else/>。基于 Something-Something V2 追加标注：**180,049 段视频、8,183,381 帧、16,963,135 个框、平均 2.41 框/帧**，类别仅为 **hand** 与 **object**。→ ✅ 有原生人工手框，但场景是**第三人称桌面操作特写**，手为中等偏大尺度，非宽场远景；**许可 UNCONFIRMED**（未取得，且 Something-Something V2 自身有独立的 20BN 条款）。
- **(b) 同名的"MOW"（Cao et al., ICCV 2021, *Reconstructing Hand-Object Interactions in the Wild*）**：[ar5iv](https://ar5iv.labs.arxiv.org/html/2012.09856)，项目页 <https://people.eecs.berkeley.edu/~zhecao/rhoi>。仅 **500 张图**，来自 Epic-Kitchens 与 100DOH，标注为**3D 手姿态 + 物体 3D 模型/位姿**（121 个物体类），**不以 2D 手框为核心**。→ 规模太小、偏 3D，**排除**。

### 2.11 额外发现：COCO-WholeBody（重要反例，必须排除）

## 3. 推荐排序与理由

### 🥇 第一：TV-Hand
- **唯一同时满足"原生人工框（非关键点推导）"与"手部尺度落在 30–90 px 区间"的公开数据集**，且是全景物、多人物、含遮挡/截断/运动模糊的电视剧-电影帧——是全部候选中最接近"转播画面"的。
- 2.3 GB 直链下载，零门槛。
- **必须先处理的风险：许可完全未声明。** 在用于论文/比赛以外的任何用途前，需邮件联系作者（Minh Hoai / Supreeth Narasimhaswamy）确认条款。
- 工程注意：框是四边形，需转成外接 AABB；源图仅 360 px 高，训练时用相对尺度增强，不要简单上采样。

### 🥈 第二：ContactHands（+ BodyHands 作为增强）
- **规模最大的人工小手段**：58,165 个手实例，且标注规则 **min(H,W)/30** 在设计上保证覆盖 1080p 下 ≥36 px 的手——正好覆盖目标尺度下沿。
- 4.5 GB / 4.6 GB 直链下载，零门槛。BodyHands 额外给人体框与手-体关联，对"判定是哪位球员"的下游很实用。
- **风险：数据许可为作者专有、仅研究用途**（仓库的 MIT 只管代码）。商用必须取得书面授权。
- 与 TV-Hand 联合训练可以直接互补：TV-Hand 提供真实转播式取景，ContactHands 提供规模与尺度分布。

### 🥉 第三（仅作预训练/负样本）：HaGRIDv2
- 唯一"规模巨大 + 直链下载 + 无注册 + 非 NC 标记 + 原生人工框"的候选，且官方附带强手检测基线（YOLOv10 mAP 88.8）。
- **但手部典型尺寸约 500×285 px，与目标差 5–15 倍**，且是单人半身取景而非宽场多人。因此**只建议用于"手部先验"预训练与 `no_gesture` 困难负样本**，不建议作为主训练集。
- 使用前**必须逐字阅读** `license/en_us.pdf`（"变体" CC-BY-SA-4.0 + ShareAlike 传染性）。

### ❌ 明确不要使用
- **COCO-Hand / COCO-Hand-S**：框由关键点推导（违反硬约束），且图像有黑色遮挡掩码。
- **COCO-WholeBody / Halpe-FullBody**：手框同样由关键点推导，且非商用。
- **EgoHands**：第一人称特写；官方下载页已失效。
- **FreiHAND**：224×224 裁剪、无框、禁商用。
- **Oxford Hand**：官方下架 + 非商用 + 12 个月期限。
- **Something-Else / MOW**：桌面特写或规模过小/偏 3D。
- **Vivid-Hands**：未找到该数据集。
