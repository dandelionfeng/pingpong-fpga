# 系统说明

硬件为 AFH03 RK3576J、PH1A90 与同步双 OV9281。拼接输入为 2560×720 MJPEG，每眼 1280×720。现场流程先保存完整原始视频，再逐对进行分析。

FPGA 执行原七级运动 Mask，mode 0、阈值 12。RK NPU 使用 YOLO-Ball 球检测模型与 YOLO-HandRacket 手拍检测模型，两者输入均为 640×640 INT8。双目采用 NPU0/1 并行执行。运动学离手候选确认后停止手拍调用，球模型继续处理全段。CPU 执行球心、双目几何、跟踪、离手与拟合；TESO 每 30 对采样一次。

运行配置沿用 FPGA-quick-field-3092-20261030。标定、世界坐标和检测/离手/拟合阈值由冻结配置提供，文件 SHA-256 保存在 manifests/model-sha256.json。板端可执行文件保留 f33387986614e0a2b2c6a24e608ab5718087c21500fdb210dbd70421246e7735。

Python 程序和浏览器界面通过本机 HTTP 接口协作，串口服务控制 J3，ADB 用于 J4 部署和取回。EXE 根据自身目录定位 app 与 runtime，服务状态和日志写入 logs。

source/native 包含基础流水线、RKNN 适配和候选停手拍的源代码。RK 重建需要与板端匹配的 OpenCV、RKNN SDK 和 JSON 头文件。现有可执行文件及模型为本次运行基线；源码重建说明与离线依赖随本地提交包保存。

界面名称 YOLO-Ball 对应原 V6 Round2 球模型，YOLO-HandRacket 对应原 Unified V2 手拍模型；文件、哈希与运行配置保持原值。

抛球高度 H = 最高点 Z − 离手点 Z；角度 θ = atan2(两点的水平距离, H)。图中使用离手点与最高点的连线表示该角度。
