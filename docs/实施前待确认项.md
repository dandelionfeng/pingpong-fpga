# AFH03 USB 同步双目实施前待确认项

更新：2026-09-30。现行路线见[方案索引](../plans/current/README.md)，申报定位为自主命题。原 H10-PH1A180 的条目保存在[历史记录](../archive/routes/v2026-09-20_h10_rk3566/docs/实施前待确认项.md)。

1. **拟采购模组**：HBVCAM-W2307-2 V11 系列双 OV9281，100°、2.1 mm 手动调焦。确认拼接 2560×720@60 和 1600×600@100 的 YUY2/MJPEG 模式表；官网旧 YUY2 表与当前商详有差异。已由用户向客服确认双目同步和手动曝光；补充同步触发机制/误差、手动曝光范围、Linux UVC 控制、缩放/裁切与左右排列资料；支架实测光心基线 150～200 mm，焦点锁定后分模式标定。详见[选型核对](OV9281_USB双目模组选型核对.md)。
2. **板卡 USB**：在 AFH03 的 RK3576J Type-C 接口确认 SuperSpeed 主机模式、供电及 5000M 枚举；J4 为 USB3 OTG0，板内 FPGA 为 PCIe1。按手册第 25、44～45 页确认 PCIe1 对另一组 USB/Hub 的复用影响，UART/有线网络用于调试，HDMI 显示；核对 J4 主机与 PCIe1 并发、CC/VBUS 和 5 Gb/s 线缆。
3. **同步和图像**：记录硬件触发或共曝光的厂商证明、左右原始序号与设备时间戳；用配对画面检查同步误差。设置短曝光和补光，逐帧核对模组标称 60 fps 与 RK 收到的完整帧率。
4. **PCIe 与 FPGA**：取得 RK 主机、FPGA 端点及双向 DMA 工程，测 主模式 640×360×2@60、对照 400×300×2@100 搜索图和 256×256×2 ROI 的持续传输；验证缓存一致性、超时和配对帧号。现有单路 640×512 图像 RTL 的双路适配需重新综合、仿真及上板。
5. **标定与模型**：完成双目内外参、世界坐标和独立球架真值；60/100 fps 两套标定及模式切换；A/B/C 评审图像到 ROI 的坐标映射、NPU 输入、量化版本与质量字段。训练、量化和独立场次分开，规则提示依据 ITTF 资料评审。
6. **验收**：设计目标与实测分栏记录左右帧率、同步、USB/PCIe 带宽、FPGA 资源及时序、三维误差、候选/检测召回、CPU/NPU 耗时和端到端 P50/P95。用同一输入比较 FPGA 启用与软件参考；保留测试命令、日志和演示数据。

以上为实施清单，摄像头型号、二进制接口和性能结论随资料与实测逐项确定。
