# AFH03 实施前待确认项

更新：2026-09-28。当前两条路线及各自文档见[当前方案索引](../plans/current/README.md)。原 H10-PH1A180 路线的待确认项保留在[历史记录](../archive/routes/v2026-09-20_h10_rk3566/docs/实施前待确认项.md)。

1. **相机与接线**：核对 SC130GS 24 针模组的实际间距、触点方向、3.3 V 供电、I²C 电平、PWDN、板载时钟及 EFSYNC。RK3576J 直采路线按底板 J8/J9 的 D0/D1 两条数据 lane 设计；FPGA 直采路线按 FMC-VID005 的实际相机口与 FPGA 引脚设计。
2. **模式与驱动**：取得模组的 2 Lane RAW10/RAW8 mode 表、发送端 lane 速率、RK3576J 传感器驱动资料和 FPGA MIPI 接收例程。先记录 120 fps 完整帧链路，再依据发送模式、带宽和处理耗时评估 240 fps。
3. **板内通信**：核对 AFH03 的 PCIe 角色、DMA 样例、双向持续吞吐与帧号对应规则。FPGA 直采路线还需确认 FMC-VID005 上的 24 针相机转接方式。
4. **测量与 AI**：确定球的距离真值采集、相机标定版本、ROI/模型预处理、网络深度与几何深度的统一定义；以独立场次报告误差和无效帧比例。
5. **资源与演示**：分别测量 FPGA 时序与资源、RK 的采集及推理耗时、端到端延迟，并准备 FPGA 启用与旁路对比。方案中的理论值与实测值分开呈现。

以上是执行入口，不冻结新的接口或性能结论。交接记录见 `handoffs/`。
