# AFH03 USB 同步双目实施前待确认项

更新：2026-10-04。现行路线见[方案索引](../plans/current/README.md)，申报定位为自主命题，按暂无实物先完成[PC 算法闭环](PC算法闭环与部署验收.md)。原 H10-PH1A180 的条目保存在[历史记录](../archive/README.md)。

1. **拟采购模组**：HBVCAM-W2307-2 V11 系列双 OV9281，沿用最新 Word 的 72°、3.6 mm 手动调焦；固定拼接 2560×720@60 YUY2。官网旧 YUY2 表与当前商详有差异；补充同步机制/误差、曝光范围、Linux UVC控制、左右排列及标称视角口径。支架实测光心基线150～200 mm，锁焦后重新标定。[选型核对](OV9281_USB双目模组选型核对.md)区分当前72°选择与旧100°商详；所购72°版本的SKU、固件、同步和模式另行登记。
2. **板卡 USB**：在 AFH03 的 RK3576J Type-C 接口确认 SuperSpeed 主机模式、供电及 5000M 枚举；J4 为 USB3 OTG0，板内 FPGA 为 PCIe1。按手册第 25、44～45 页确认 PCIe1 对另一组 USB/Hub 的复用影响，UART/有线网络用于调试，HDMI 显示；核对 J4 主机与 PCIe1 并发、CC/VBUS 和 5 Gb/s 线缆。
3. **同步和图像**：记录硬件触发或共曝光的厂商证明、左右原始序号与设备时间戳；用配对画面检查同步误差。设置短曝光和补光，逐帧核对模组标称 60 fps 与 RK 收到的完整帧率。
4. **PCIe 与 FPGA**：先用CPU整数参考和RTL验证七级运动前端、同眼前帧/复位、随机背压与掩膜打包；缺官方IP/目标综合环境单列。取得AFH03 RK主机/FPGA端点的双向DMA工程后，实测双搜索图H2C 27.648 MB/s与掩膜C2H 3.456 MB/s设计载荷下的持续链路，验证DDR3L、缓存一致性、超时和帧号。H10 CK203 DDR3证据单列；ROI在CPU原图中裁切。
5. **标定与模型**：PC完成公开棋盘练习、独立双目投影/世界系及事件观测测试，真实相机到后另做最终内外参与独立位置验证；公开数据三类模型先完成PC工具链，真实灰度域补训和INT8校准后另验。A/B/C评审取整、ROI映射、NPU输入/归一化、前帧、质量及来源帧号；训练、校准与独立场次分开，判罚依据与不确定度经评审。
6. **验收**：设计目标与实测分栏记录左右帧率、同步、USB/PCIe 带宽、FPGA 资源及时序、三维误差、候选/检测召回、CPU/NPU 耗时和端到端 P50/P95。用同一输入比较 FPGA 启用与软件参考；保留测试命令、日志和演示数据。

7. **日期与设备状态**：10月12日为PC总验收目标，当前暂不依赖任何实物。AFH03按13日下单、运输约1～2日估计，实际到货日记D；相机先到即可补实际输入，H10是可选项。日期不表示任务完成，到货后调试按D相对排期。

以上为待实施清单，二进制接口和性能结论随评审、资料与实测逐项确定。本次修订仅完成文档，没有运行算法或验证硬件。
