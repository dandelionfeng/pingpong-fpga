# 当前 AFH03 USB 同步双目技术路线

更新：2026-10-04，无硬件 PC 算法闭环版。当前按自主命题准备。入口是[技术路线 Markdown](usb-stereo/技术路线_AFH03与USB同步双目测量方案.md)、[Word](usb-stereo/技术路线_AFH03与USB同步双目测量方案.docx)、[PDF](usb-stereo/技术路线_AFH03与USB同步双目测量方案.pdf)；[三人分工](../../项目规划/AFH03_USB同步双目方案一个月分工/00_三人分工与一个月实施安排.md)另有[Word 版](../../项目规划/AFH03_USB同步双目方案一个月分工/00_三人分工与一个月实施安排.docx)，A/B/C 的个人说明见同目录。输入包、测试矩阵和迁移步骤见[PC 算法闭环与部署验收](../../docs/PC算法闭环与部署验收.md)。

双目模组选 72°、3.6 mm 手动调焦双 OV9281；固定 YUY2 拼接 2560×720@60，每眼 1280×720，基线 15～20 cm。正式由 RK3576J USB 输入，RK 留原图，经 PCIe1 发送双眼 640×360 搜索图；PH1A90SEG324 FPGA 运行七级运动流水线并返回 1 bit 掩膜。CPU 完成候选、同帧原图 ROI 球心、标定、三维和事件，NPU 提供三类语义。到货前以文件、整数软件前端及 PC 模型运行共用算法核心，RTL 离线逐级对照。

本版的 60 fps、带宽、资源和延迟先按理论设计；完整链路以选定模组和 AFH03 实测为准。赛事选题三列有 FPGA MIPI CSI 采集及硬件压缩必做项，因此本版按自主命题申报。[历史 FPGA 直采 MIPI 方案](../../archive/routes/v2026-09-28_afh03_sc130gs_fpga_mipi/技术路线_AFH03与SC130GS单目测量方案.docx)、[历史 RK 直采 MIPI 方案](../../archive/routes/v2026-09-28_afh03_sc130gs_rk_mipi/技术路线_AFH03与SC130GS单目神经网络测距方案.docx)和[旧分工](../../archive/routes/v2026-09-28_afh03_sc130gs_mipi_team/00_三人分工与一个月实施安排.docx)保留原内容以便回查。

现有 FPGA 图像模块和[验证记录](../../reports/AFH03图像处理验证.md)作为行缓存与流控参考，新双路七级运动流水线的像素、接口、时序和资源重新验证。模型输入、ROI 坐标、量化与阈值由 A/B/C 用黄金样例联合评审；规划不代表二进制协议已经冻结。10 月 12 日为 PC 总验收目标，实物按实际到货日 D 另验。H10 CK203 是可选 RTL 预验证平台。

[选型核对](../../docs/OV9281_USB双目模组选型核对.md)已按当前 72° 方案更新，区分现行选择与旧 100° 商详/客服记录，并说明固定 YUY2 模式仍需具体版本确认。实施前阅读 [GitHub 使用指南](../../docs/协作使用指南.md)、[AI agent 指南](../../docs/AI_agent协作指南.md)和[最新交接索引](../../handoffs/README.md)。当前完整 PC 闭环与现行七级 RTL 尚待实施，历史图像模块结果见[报告索引](../../reports/README.md)。
