# V8-Hand 轮 · 执行摘要

日期：2026-10-29　分支：`codex/c-pc-detector`　起点：`99fe08e`

## 结论

**V8-Hand 训练完成，Hand 在模型层面确有提升（AP50 +0.022、F1 +0.008），但 Ball（R −14 点）
与 Racket（R −8 点）明显退化 → 不替换 V3，不生成交付 ZIP。**

## 1. 最重要的发现（审计）

**Hand 的评测集是影视剧画面，不是乒乓球。** 400 张 `vbh_*` 全是 TV/电影场景
（病房、影院观众席、街头、树林），且**只标注"关注的手"**：同一张图里明显有多只手，
只框了 2–3 个（`visuals/val_hand_gt_sheet.jpg` 可证）。

**没有任何一张图具备完整、人工确认的三类标注**（4,940 张逐图审计：4,640 张 INCOMPLETE_LABELS，
300 张负样本，**0 张完整**）。tabletennis 的 2,110 帧**完全没标 hand**。

## 2. Hand 错误分析（V3）

| 项 | 结果 |
| --- | --- |
| 主要归因 | **TOO_LOW_SCORE 377/518（72.8%）**，其次 NO_CANDIDATE 96、BAD_LOCALIZATION 45、**WRONG_CLASS 0** |
| 尺寸 | **<48 px 占 FN 的 77%** |
| FP | 292 个，**100% BACKGROUND**，291 个来自影视剧图，框宽中位 33 px、分数中位 0.38 |
| FP 性质判断 | 很可能是**真实但未标注的手**（目视抽查支持），即 Precision 被系统性低估 |
| 匹配手分数 | p10 0.334 / p50 0.645 / p90 0.799，**无一个 TP 低于 0.25** |
| 每图检测数 | 400 张有手 GT 的图里，**150 张一个手都没检出** |
