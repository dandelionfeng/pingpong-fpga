# B 第二部分：球心测量 v2 验证

日期：2026-10-06。当前范围为局部球区域选择/误检、固定 ROI 与帧身份、质量和预测位置补测。依据技术路线 2.5 与 B 职责。源码目录 software/pc_pipeline/ball_measurement/；接口仍为 b-measure-v2-draft，未冻结二进制布局。

## 本轮结果

Windows MSVC C++17 Release 配置、编译、链接和 3 组 CTest 全部通过。共 42 个检查：selection 12，identity 16，quality 14。另由 C++ CLI 从独立生成的图片和元数据运行 54 个场景，评分器单独读取真值，54/54 通过。35 个清晰合成场景涵盖直径 12/20/32/40 px、亮/暗极性、原图中部和需补齐位置、两眼及小数球心。清晰场景误差 P95=0.0725405931 px。数值用于受控输入验证，不代表真实相机精度或全项目验收。

主要修复：均匀背景有 Mask 时拒收；局部多前景只计算选中连通域 moments；亮暗极性同时检查并比较周围背景；3×3 平滑、闭运算后用面积/宽高比/圆度/对比度拒收无效区域。候选最多八个，结合预测距离排序；旧位置 Mask 在当前原图无真实区域时拒收。等价多候选标 ambiguous，预测门限外的另一个圆形对象拒收。

ROI 固定 256×256，记录 requested_roi、image_valid、roi_valid、local_window 与 local_valid，replicate 补齐像素不计入分割；非连续 Mat/行步幅、四个图像角及坐标映射有逐像素检查。轮廓截断时记录质量后拒收，无效球心不以粗中心冒充观测。

正式单眼接口检查 pair_id、eye、ns 采样时间、mode/config/calibration、正在运行的配置版本和 reference_id；双眼入口检查同帧及眼别顺序。失败/未初始化 Mask 与过期/错帧预测拒收。预测补测成功为当前像素 observed，预测单独保留；无球为 prediction-only 且无 observation。时间差先用整数相减，覆盖大 ns 时间戳。

质量保存对比度、宽高比、圆度、前景占比、Sobel 强度及方位支持、不对称与凸包充实度、图像/ROI/局部边界及可能遮挡。轻度遮挡 observed_reduced_quality，严重形状或边界拒收。这是质量提示，不是真实遮挡识别；轻度遮挡 moments 可以有偏差。
