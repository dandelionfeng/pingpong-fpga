# FPGA-AI 乒乓球发球判罚辅助系统

2026 FPGA 创新设计竞赛团队仓库。当前是规划与协作基础设施阶段，尚无通过验收的产品代码。

当前路线以 [实施规划 v1.3](项目规划/项目实施规划.md) 为准：PH1A180 前端 + 双目 OV9281 → FPGA 预处理和 ROI → 千兆网 UDP → RK3566 模型推理、双目几何、判罚辅助与显示。使用安路器件不等于参加选题三。

## 从这里开始

1. 阅读 [多人协作使用指南](docs/协作使用指南.md)，完成账号、克隆和本地初始化。
2. 阅读 [接口与验收契约](项目规划/接口与验收契约.md) 和 [实施前待确认项](docs/实施前待确认项.md)。
3. 每个任务建一个分支，完成后通过 Pull Request（PR）合入 main。
4. 给 AI 的交接材料见 [原交接包](项目规划/Agent协作交接包.md)、[AGENTS.md](AGENTS.md) 和 [任务交接模板](handoffs/TEMPLATE.md)。

## 目录与负责人

| 目录 | 内容 | 默认负责角色 |
|---|---|---|
| fpga/ | RTL、仿真、约束、可重建工程脚本 | A：采集/同步/DDR/顶层；B：预处理/ROI/UDP |
| rk3566/ | 接收、RKNN 推理、几何、状态机、界面 | C，B 协助协议联调 |
| vision/ | 训练、量化、标定代码 | C |
| contracts/ | 经评审冻结的协议、格式、测试向量 | B+C，硬件接口由 A 参与 |
| tests/、tools/ | 自动检查、开发工具 | 三人共同维护 |
| reports/、handoffs/ | 实测证据、任务交接 | 任务执行人 |
| data/manifests/、artifacts/ | 大文件来源、校验和与版本说明 | 产出人 |
| 项目规划/ | 团队现有规划原件 | 队长协调修改 |

目前的自动检查只检查仓库卫生，不代表 RTL 仿真、综合、时序或板级功能通过。硬件性能、模型精度和延迟必须记录实测证据。
