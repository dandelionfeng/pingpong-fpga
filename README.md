# FPGA-AI 乒乓球发球测量项目

2026 FPGA 创新设计竞赛团队仓库。目前处于技术路线和基础模块开发阶段；方案中的帧率、精度及端到端性能均以之后的板级记录为准。

## 当前保留的两条 AFH03 单目路线

以 [当前方案索引](plans/current/README.md) 为入口。两条路线共用 MLK-AFH03-AFC03 与 SC130GS 全局快门相机，区别在于**相机先接到哪里**：

1. [相机进入 FPGA](plans/current/fpga-direct/技术路线_AFH03与SC130GS单目测量方案.docx)：经已向客服确认可接 AFH03 的 FMC-VID005 相机转接板进入 FPGA，由 FPGA 采集和预处理，RK3576J 负责识别及几何测量。24 针相机与转接板之间的针脚、电平和线缆仍需对照。
2. [相机进入 RK3576J](plans/current/rk3576-direct/技术路线_AFH03与SC130GS单目神经网络测距方案.docx)（[PDF](plans/current/rk3576-direct/技术路线_AFH03与SC130GS单目神经网络测距方案.pdf)）：使用底板 J8/J9 的 MIPI CSI，当前按相机两条数据 lane 设计。RK3576J 保存原图，FPGA 经板内 PCIe 处理逐帧灰度搜索图并返回候选，RK3576J 完成裁剪、NPU 测距和 CPU 三维轨迹。对应的[三人一个月分工](项目规划/AFH03单目方案一个月分工/00_三人分工与一个月实施安排.docx)只适用于这条路线。

底板 J8/J9 的相机 MIPI CSI 接到 RK3576J；FPGA 直采路线使用 FMC 扩展接口及独立转接板。两条路线尚待相机接线、驱动、帧率和板内传输实测。选型及协议在三人评审前属于方案稿。
