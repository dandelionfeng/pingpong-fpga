# FPGA AI 乒乓球发球测量项目

2026 FPGA 创新设计赛道团队仓库。当前按**自主命题**准备 AFH03 USB 同步双目测量方案；帧率、精度、延迟和功耗均以之后的实物记录为准。

## 当前方案

从[当前方案索引](plans/current/README.md)进入[技术路线](plans/current/usb-stereo/技术路线_AFH03与USB同步双目测量方案.md)和[三人一个月分工](项目规划/AFH03_USB同步双目方案一个月分工/00_三人分工与一个月实施安排.md)。成品同步双目模组经 RK3576J 的 Type-C SuperSpeed USB 接入；RK 保存左右原图，板内 PCIe 将缩小的双路搜索图与局部 ROI 交给安路 FPGA。FPGA 做双路候选与球心硬件测量，RK CPU 做标定和三维轨迹，NPU 识别球、手和球拍。

拟采购 HBVCAM-W2307-2 V11 系列 100°手动调焦双 OV9281 USB3 模组。主模式拼接 2560×720@60、每眼 1280×720，对照拼接 1600×600@100、每眼 800×600；支架光心基线 15～20 cm。商详标 UVC/Linux，用户已向客服确认双目同步和手动曝光；当前 YUY2 模式、同步机制及误差继续核对。高速摄像头接 J4 USB3 OTG0，板内 FPGA 为 PCIe1；普通 USB2 Host/Hub 依接口复用关系核对，UART 与有线网络承担主调试。原两份 MIPI 单目方案及旧分工已按版本归档。赛事选题三要求 FPGA MIPI 采集和硬件压缩，本版采用自主命题定位。
