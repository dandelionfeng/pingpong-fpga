## 5. 判读

| 问题 | 结论 |
| --- | --- |
| **Ball Recall 是否提升** | **没有，反而大幅下降**（0.460→0.370 AP 口径；部署阈值下 0.510→0.350）。1280 假设**被证伪** |
| Racket 是否退化 | **没有，是历史最好**：AP50 0.738→**0.770**、R 0.727→**0.744**、AP50-95 0.347→**0.359** |
| Hand 是否退化 | AP50 0.607→0.603（持平），但 **P 0.679→0.561** 明显下降、R 0.538→0.591 上升（工作点漂移） |
| 整体 | V5 overall mAP50 0.606 < V3 0.627 → **综合不如 V3** |
| 速度 | 1280 慢 1.72×，对现有 PC 链路仍有压力 |

**重要归因限制**：V5 相对 V3 同时改变了**分辨率（1280）、batch（8 vs 12）、epochs（10 vs 15）**，
因此不能把 ball 下降单独归因于分辨率。但可以确定：**"上 1280 就能救小球"这个假设不成立**。

## 6. 结论

- **V5 未通过交付门槛（核心指标 Ball Recall 明显低于 V3）→ 不交付、不替换 V3**；
- 但 V5 给出一个**可复用的正面结论**：**1280 显著提升 Racket（AP50 +3.2 点、AP50-95 +1.2 点）**，
  如果后续做成"球拍用 1280 分支 / 球用 960 分支"，或统一模型未来上 1280 时优先保 racket，V5 权重有价值；
- 若必须单选一个统一模型：**V3**（ball F1 0.630 + racket F1 0.758，速度 56.8 ms）。
