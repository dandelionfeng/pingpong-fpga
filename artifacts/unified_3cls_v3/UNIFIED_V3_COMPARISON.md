## 3. 判读

| 问题 | 结论 |
| --- | --- |
| Ball 是否提升 | **部分**：AP50 +0.019、F1@0.25 +0.057、误检从 18 降到 5；**但 Recall 没升**（−0.015） |
| Racket 是否提升 | **是**：Recall +0.048、F1 +0.044、AP50 +0.003 |
| Hand 是否退化 | 基本持平（AP50 −0.006 / F1 −0.008），在噪声范围内 |
| 是否只是某个 val 过拟合 | 无法完全排除（同一 val，无独立测试集）；但 ball 的误检大幅下降属于泛化性质的改善 |
| 类别混淆是否增加 | 未观察到（racket→hand 误分类未见于统计） |
| 推理耗时 | V3 74.0 ms vs V2 70.4 ms（+5%），仍可用 |

## 4. 结论

V3 是**真实但有限**的改进：目标两类在部署阈值下的 F1 都提高了 4–6 个点，Hand 没有明显退化。
但 **Ball Recall 0.46 仍是最大短板**，且所有数字来自同源 val，因此：

- **保留 V2 作为默认交付**，V3 作为**新的实验候选**并行提供；
- 不宣称 V3 是"正式验收版本"。
