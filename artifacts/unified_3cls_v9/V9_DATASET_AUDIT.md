# V9 双分类数据审计（Ball + Hand）

日期：2026-10-30　源：`pingpong_unified_3cls_v4`　构建：`tmp/build_v9_dataset.py` → `pingpong_v9_ball_hand`

## 1. 各来源的标签完整性（实测）

| 来源 | 训练帧 | 有 ball | 有 hand | 有 racket | 判定 |
| --- | ---: | ---: | ---: | ---: | --- |
| tabletennis `tt` | 1,055 | 989 | **0** | 1,052 | **缺 hand** |
| tabletennis `tt2` | 1,055 | 989 | **0** | 1,052 | **缺 hand** |
| BNDSTT `ps` | 521 | 521 | 436（自动候选） | 0 | ball 可靠；hand 为自动 |
| bodyhands `bh` | 700 | 0 | 700 | 0 | hand 有；**无 ball** |
| hand_pseudo `pp` | 400 | 0 | 400 | 0 | hand 有；**无 ball** |

| 负样本 `bg/hn` | 300 | 0 | 0 | 0 | 真无目标 |

**同时具备 ball 与 hand 标注的帧：436（全部来自 ps）。**

## 2. 关键发现：自动补标在 tabletennis 上失效

按任务要求"不能把未标注的真实目标当背景"，我尝试用 V3 给 2,110 张 tabletennis 帧补 hand 候选
（conf ≥ 0.45）：

| 测量 | 结果 |
| --- | ---: |
| 抽样 20 帧的 hand 检测数 | **0** |
| 最高 hand 分数 | **0.000** |
| 全量 2,110 帧补出的 hand 框 | **0** |

→ **V3 的手部检测头在广角球台画面上完全看不到手**（手在 960 输入下极小）。
所以"自动补 hand 标注"这条路在本数据上**不可行**——不是配置问题，是模型在该尺度上没有能力。

这同时说明：**tabletennis 帧里的手客观存在但无法被标注或补标**，
在这些帧上训练任何模型都会把真实的手学成背景。

## 3. 本轮采取的方案（与 V3 完全同数据，保证可比）

| 项 | V9 训练集 | 说明 |
| --- | ---: | --- |
| 帧数 | **4,431** | 与 V3 完全相同 |
| ball 框 | **2,499** | 与 V3 相同 |
| hand 框 | **3,698** | 与 V3 相同 |
| **racket 框** | **0** | **全部剔除**（V9 不再有该类） |
| val | 509 帧 / ball 100 + hand 1,172 | 与 V3 相同（racket 176 框在评测中忽略） |

**为什么不用"更干净的小集"**：若只保留 ball+hand 双标注的 436 帧 + hand 帧，ball 框会从 2,499
掉到 521，Ball 召回必然崩；而任务是 Ball 优先。因此本轮选择**与 V3 完全相同的训练数据**，
只去掉 racket 类，使"2 类 vs 3 类"成为**唯一变量**——这样才能公平回答"去掉 racket 是否让球更好检"。

⚠ 代价（如实记录）：V9 与 V3 一样，在 tabletennis 帧上把真实的手当背景训练。
这是**继承自 V3 的已知偏差**，不是本轮新引入的；两者对比因此仍然公平。

## 4. 验证集完整性

| 检查 | 结果 |
| --- | --- |
| vtt（109 帧） | 有 ball GT，**无 hand GT** → 只用于 Ball 指标 |
| vbh（400 帧） | 有 hand GT，**无 ball GT** → 只用于 Hand 指标 |
| 空标签帧 | 9 帧（V3 时期 74 帧里有 ball/racket 的空标注；此处按 2 类重算为 9） |
| 是否会因为缺少 racket 而虚高 | 否：racket GT 直接不参与统计 |

因此 **Ball 与 Hand 的指标分别来自不同子集**，这一点在评测报告中已注明。

## 5. 重复帧检查

`tt` 与 `tt2` 是同一批帧的两个前缀（各 1,055，去重后 1,055）。
这一点在 V3 数据里已存在，**未在本轮改变**，对两个模型的对比无影响。

## 6. 结论

1. **本数据无法构造"干净的双分类训练集"**——ball 域没有 hand 标注，hand 域没有 ball 标注，
   且自动补标在 ball 域完全失效（0 检出）。
2. 本轮采用"同数据、去 racket"的受控方案，把 2 类 vs 3 类隔离成唯一变量。
3. 真正的解决办法只有一个：**在 tabletennis 广角帧上人工标注手**（我们目前没有任何这类标签）。
