# V9 模型结构改造报告（3 类 → 2 类）

日期：2026-10-30　脚本：`tmp/make_2cls_from_v3.py`
源：`artifacts/runs/unified_3cls_v3b/weights/best.pt`（V3，nc=3）
产物：`artifacts/runs/v9_init_2cls.pt`

## 1. 改了什么（结构级，不是改名字）

| 部件 | 处理 | 证据 |
| --- | --- | --- |
| Backbone（layer 0–9，含 SPPF） | **原样复制** | 参数量与 V3 一致 |
| Neck（layer 10–21） | **原样复制** | 同上 |
| Box/DFL 分支（`cv2` + `dfl`） | **原样复制** | 类别无关，输出仍 4×16 通道 |
| **分类分支 `cv3`（3 个尺度）** | **重建为 2 通道**，权重取 V3 的第 0、1 通道 | 每支 `out_channels` 由 3 → **2** |
| `nc` / `no` | 3 → **2** / 69 → **66** | 见下 |
| 类别名 | `{0: ball, 1: hand}` | — |

Racket 通道（原第 2 通道）**被丢弃**，不是改名。

## 2. 结构自检（脚本内断言，全部通过）

| 检查 | 结果 |
| --- | --- |
| 每支 `cv3` 尾部卷积输出通道 | **[2, 2, 2]** ✅ |
| `det.no`（训练态原始通道数） | **66** = 4×16 + 2 ✅ |
| eval 模式前向输出 | **(1, 6, 18900)** = 4 框 + **2 类** ✅（V3 是 `[1,7,18900]`） |
| 保存后重新加载 | `nc=2  no=66  cv3 out=[2,2,2]` ✅ |
| 参数量 | 见 `V9_MODEL_SURGERY.json` |

**6 通道输出是"真双分类"的硬证据**——不是把三分类模型改名或截断 ONNX 输出。

## 3. 权重复用情况

| 部分 | 复用比例 |
| --- | --- |
| Backbone + Neck + Box/DFL | **100%**（V3 原权重） |
| 分类分支 | ball/hand 两支通道 **原样复用**；仅去掉 racket 的 1 个输出通道 |

参数张量层面：`cv3` 每支最后一层卷积由 `(3, C, 1, 1)` → `(2, C, 1, 1)`，
`weight[:2]`、`bias[:2]` 直接拷贝。
