# V7_TILE_DATA_AUDIT — 原图滑窗图块的数据审计

日期：2026-10-26　构建脚本：`tmp/build_v7_tiles.py`

## 1. 目标与原理

V3 的全图路径：1920×1080 → letterbox 960，**scale = 0.5**，于是 val 中位 24.5 px 的球只剩 **12.2 px**。
V7 的滑窗路径：从 1920×1080 原图**按 1:1 裁 960×960 图块**，球保持 **24.5 px**。

## 2. 源数据审计（训练集）

| 项 | 实测 |
| --- | --- |
| 源 | `pingpong_unified_3cls_v4` train，4,431 图 |
| 分辨率分布 | **1920×1080**（tabletennis + BNDSTT）与 **480×360 等小图**（bodyhands 手部集，1,500 图）混排 |
| 类别组合 | (ball+racket) 1,972、(hand) 1,500、(ball+hand) 436、(空) 300、(racket) 132、(ball) 91 |
| GT | ball 2,499 / hand 3,698 / racket 4,790 |

## 3. 裁切规则（三类完全一致）

| 规则 | 值 |
| --- | --- |
| 窗口 | 960×960，**1:1 裁切，不缩放** |
| 步长 | x 方向 480，y 方向 120（1920×1080 最多 6 个窗口） |
| 保留框条件 | **框中心必须落在窗口内** —— 宁可丢弃被截断的目标，也不把截断物当完整物标 |
| 截断处理 | 中心在内后按窗口裁剪并重新归一化 |
| 最小残框 | < 4 px 丢弃 |
| 每帧窗口上限 | **4**（含球优先，其次框数多者） |
| 小图（< 960） | 无法裁切 → 按 letterbox 补齐到 960×960（与原流程一致；这些小图无 ball GT） |
| **val** | **逐字节复制，绝不裁切、绝不训练** |

## 4. 生成的图块集

| 项 | 值 |
| --- | --- |
| 图块数 | **13,451** |
| letterbox 小图 | 699 |
| 未产出任何图块的帧 | 300（负样本帧，无 GT） |
| 图块内 GT（曝光计数） | ball 9,822 / hand 7,449 / racket 13,836 |
| **图块内球宽** | p10 **18.8** / p50 **26.9** / p90 **42.7 px** |
| 对照全图 @960 | p10 9.4 / p50 13.6 / p90 21.6 px |

→ **球的有效像素尺寸放大约 2 倍**，与 val 的原生尺度 24.5 px 对齐：**机制成立**。

## 5. 实际训练用的子集（控时）

| 项 | 值 |
| --- | --- |
| 图块池 | ball 9,822 / hand-only 3,634 / racket-only 694 |
| 采样配额 | ball 4,000 + hand 1,500 + racket-only 500 = **6,000** |
| 子集 GT | ball 4,000 / hand 3,137 / racket 5,923 |

## 6. 泄漏与隔离检查

| 检查 | 结果 |
| --- | --- |
| val 图块是否进训练 | **否**（训练集 6,000 张全部来自 train 帧） |
| val 是否被裁切后训练 | **否** |
| 同一帧的多窗口是否跨集合 | **否**（训练与 val 的比赛/视频级别隔离沿用 V3 的划分） |
| 训练集内部重复 | 同一帧最多 4 个重叠窗口 → **同一目标会被多次曝光**（这是刻意的采样放大，不是新数据） |
| 是否使用伪标签 | **否** |

## 7. 图块域验证集（仅用于选点，不参与训练）

为修正"用全图 val 选图块模型"的错配，另建 `pingpong_v7_val_tiles`：
从**同一 509 张 val 帧**裁出 **629 个图块**（ball 392 / racket 686 框）。

**已知局限**：这些图块里**没有 hand 框**——hand 只存在于 480×360 小图，无法裁 960 窗口。
因此图块域 val 只能反映 ball/racket 的选点质量，hand 需要用原始全图 val 单独核查。

## 8. 审计结论

机制、坐标、标签规则均通过；**球尺寸放大 2 倍属实**。
风险点：图块域与全图域之间是**两个不同的输入分布**，V7 必须在"滑窗推理"下使用，
全图推理会因尺度错配大幅掉点（已实测，见 `V7_COMPARISON.md`）。
