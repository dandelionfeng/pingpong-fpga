阈值：ball 0.20、racket 0.25 冻结；hand 见扫描表。**未改动任何模型权重。**

## 4. FP 分析（阈值 0.25，共 292 个）

| 项 | 结果 |
| --- | --- |
| 归因 | **BACKGROUND 292（100%）**，无类别混淆、无"部分目标" |
| 来源 | **291 个来自 `vbh_*`（影视剧图）**，1 个来自 `vtt_*` |
| 分数分布 | p10 0.27 / **p50 0.38** / p90 0.63；≥0.6 有 **36** 个，≥0.4 有 **127** 个 |
| 框宽 | p10 15 / **p50 33** / p90 81 px |

**关键判断：这些 FP 很可能是"真实存在但未标注的手"。**
依据：目视抽查 `visuals/val_hand_gt_sheet.jpg`（6 张高分 FP 图）——病房、观众席、街头等影视场景，
画面中明显有多只手，而 GT 只框了 2–3 只。标注策略是"标关注的手"，不是"标所有手"。

→ 因此 **Hand 的真实 Precision 高于 0.691**，但**无法在现有标签下量化**。

## 5. 每图检测数（阈值 0.25）

400 张有手 GT 的图里，**150 张一个手都没检出**（37.5%）——这是 Recall 0.558 的直接来源。

## 6. 置信度分布（匹配上的 654 个 TP）

p10 **0.334** / p50 **0.645** / p90 **0.799**；**没有一个 TP 的分数低于 0.25**（0%）。

→ 说明"低分但正确"的情况主要集中在**未被阈值采纳的那些**（即第 2 节 377 个 TOO_LOW_SCORE），
它们分数在 0.10–0.25 之间。

## 7. 结论

1. **主要错误是"小手漏检"**（77% 的 FN 是 <48 px），不是类别混淆（0）。
2. **阈值已最优**，没有可挖的 F1 空间。
3. **FP 很可能是漏标**（影视剧里只标了关注的手），Precision 被系统性低估。
4. 想真正提升 Hand，需要的是**完整的手部标注**（尤其是乒乓域），而不是继续调训练。
5. 与 Ball 的结论一致：**小目标 + 标注密度**是共同瓶颈。
