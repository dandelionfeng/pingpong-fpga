## 3. 判定

| 门槛 | 结果 |
| --- | --- |
| Hand Precision ≥ 0.75 | ❌ 0.688 |
| Hand Recall ≥ 0.65 | ❌ 0.573 |
| Hand F1 ≥ 0.70 | ❌ 0.625 |
| Ball Recall 不低于 V3 (0.510) | ❌ **0.370** |
| Racket Recall 不低于 V3 (0.756) | ❌ **0.676** |
| 不增加无目标帧误检 | ⚠ hand FP 292→304，明显上升 12 |

**Hand 目标三项全部未达到；且 Ball/Racket 明显退化。**

## 4. 结论

**V8-Hand 不替换 V3。**

- 它确实让 Hand **在模型层面**变好（AP50 +0.022、F1 +0.008、召回 +0.015、分数标定更准）；
- 但代价是 Ball 召回 −14 点、Racket 召回 −8 点——因为训练时把 1,500 张 hand 帧各复制了一份，
  **改变了训练分布**，稀释了球/拍的样本占比；
- 这种"拆东墙补西墙"的改动不能接受。

**保留 V3。** 若将来确实需要更强的 hand，正确做法是**补标乒乓域的 hand**
（当前只有 575 个自动候选，无人工标注），而不是在影视剧数据上做重采样。
