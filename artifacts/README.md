# 大文件与可复现记录

模型权重、板卡镜像、视频、厂商 SDK 与 FPGA 编译产物不进入普通 Git 历史。使用团队有权访问的存储；有授权的交付产物也可放私人仓库的 Release 附件。链接不能包含临时授权令牌。

每份产物在 data/manifests/ 建清单，填写：名称、版本、下载位置、访问权限、SHA256、字节数、生成源码提交号、工具版本、板卡/相机参数、模型输入输出、量化参数、生成步骤、授权范围。下载后核对 SHA256；Windows 可用 `Get-FileHash -Algorithm SHA256 路径`。

本仓库未启用 Git LFS，不产生由本配置主动购买的存储服务。不要用删掉文件再提交的方式清理已进入历史的密钥或大文件，先联系队长处理历史与凭据轮换。
