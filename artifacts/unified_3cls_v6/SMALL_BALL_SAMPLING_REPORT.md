## 2. 采样策略（规则先定，后训练）

| 规则 | 值 |
| --- | --- |
| 触发条件 | 该帧**已有一个可靠 ball GT**，且最小球宽 < 16 px |
| 极小球（< 10 px） | 追加 **2** 份（合计 3× 曝光） |
| 小球（10–16 px） | 追加 **1** 份（合计 2× 曝光） |
| 单帧上限 | **2 份**（防止极端过采样） |
| 总预算 | 追加量 ≤ 基础集 **20%** |
| 分配顺序 | 按球宽**从小到大**，稀缺的极小球优先 |
| 标签 | **完全不动**，只复制已有标签 |
| val | **完全不动**（509 图） |

## 4. 曝光统计与防滥用核对

| 检查 | 结果 |
| --- | --- |
| 单帧最大曝光 | **3×**（159 帧），其余 ≤2× ✅ |
| 是否把副本算成新 GT | **没有**。报告中 `train_0 = 3,385` 是**曝光计数**（2,499 真 GT + 886 副本），**不是新增标注** |
| 是否影响 Hand/Racket 覆盖 | 复制的是整体帧，Hand/Racket 标签一起复制 → 曝光同比上升，未被削弱 |
| 是否用 val 图 | **否** |
| 是否用低置信伪标签 | **否** |
| 每个 epoch 预期构成 | 5,317 图，其中 886 张是"小球帧的副本"，其余 4,431 是原始帧 |

## 5. 局限

1. 这是**加权曝光**，不是新的信息——无法凭空创造 19–24 px 的新球样本；
2. 3× 曝光的 159 帧存在轻微过拟合风险，已通过**只跑 12 轮 + 早停**缓解；
3. 若 V6 的 Ball Recall 仍无提升，说明**数据密度问题无法靠重采样解决**，只能人工补标。
