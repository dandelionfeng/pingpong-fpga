# A USB 采集与 FPGA 链路职责说明

你负责把同一次曝光的左右图像稳定送进处理链，并让 FPGA 的候选准确回到原始双目帧。准备周期为 2026-09-29 至 2026-10-28；当前路线按自主命题设计。[R1]

## 你的工作怎么串起来

先接入拟采购 HBVCAM-W2307-2 V11 系列 100°手动调焦双 OV9281 模组。AFH03 接入点为 J4 USB3 OTG0，板内 FPGA 为 PCIe1；普通 USB2 Host/Hub 随复用关系核对，UART 和有线网络承担主调试。核对主机角色、5 V、支持 5 Gb/s 的 C 至 C 线或 USB3 主机转接件。[R2]

用 `lsusb -t` 查 5000M，`v4l2-ctl --list-formats-ext` 与 `--list-ctrls-menus` 查模式和曝光。主模式拼接 2560×720@60，左右各 1280×720；对照拼接 1600×600@100，左右各 800×600。YUY2 优先；厂家官网旧表与商详的 YUY2 帧率有差异，以当前固件模式表确认，MJPEG 作为接入备选。收到一个拼接帧再拆左右，配对序号和曝光同步证据分别保存。

每对图像分配 `pair_id`，分别保存左、右原图和UVC 帧序号、可用设备时间戳、主机接收时间、像素格式、行步幅及配置版本。原图放 RK 环形缓存，保持到 FPGA 候选返回、ROI 裁切与证据保存完成。主模式 USB YUY2 纯像素流量约 221.184 MB/s，100 fps 对照约 192.000 MB/s；提取 Y 后双灰度分别为 110.592、96.000 MB/s。8 对灰度缓存分别约 14.7456、7.68 MB，覆盖约 133.3、80 ms。实际缓存按格式和步幅重新核算。[R1]

从同一对原图生成当前模式左右各 640×360 或 400×300 GRAY8 搜索图，通过 PCIe H2C 送 FPGA；接收 B 的双路候选后，从同一 `pair_id` 取左右 256×256 ROI，你实现裁切、重映射和坐标恢复，按 B 定义的标定语义形成配对局部图，再送 FPGA 做球心细化。搜索图加每帧一对 ROI 的纯载荷主模式约 35.51232 MB/s、对照约 37.10720 MB/s。B 的候选与球心经 C2H 返回，A 负责超时、排队、缓冲释放、配置生效帧与丢帧记录。PCIe 2.0×1 每方向约 500 MB/s 是编码后理论上限，DMA 吞吐由板上计数确定。[R3]

FPGA 侧你负责 PCIe 输入输出、数据包解帧、DDR 前帧访问、队列、时钟复位和 B 的 RTL 顶层集成。B 负责滤波、帧差、形态学、候选及球心算法。先用递增棋盘格、角点亮斑、错序帧及暂停消费者测试；每次回包都带 `pair_id`，使 C 的模型和 B 的三维结果可回查原图。

## 每周交付

- 第 1 周：本款当前固件模式/同步/曝光证据、J4 与 PCIe1 并发及 Hub 复用记录、成对文件模拟采集、H2C/C2H 合成帧回环；与 B/C 评审像素格式、坐标和缓冲寿命。
- 第 2 周：真实双目采集、左右完整帧率与配对日志、搜索图进入 FPGA 并返回候选；静态球原图回查。
- 第 3 周：同帧双 ROI 往返、回放界面和事件原图保存；持续队列与错误恢复。
- 第 4 周：连续运行、USB/PCIe 吞吐与 CPU 占用；同一批帧上对照 FPGA 和 RK 软件搜索，整理 P50/P95 延迟及演示脚本。

采集与基础框标注由三人分担；你额外负责参考录像、板端日志和展示界面。第 1 周交给 B/C 的最小包是左右原图、搜索图、`pair_id`、格式、步幅、缩放规则及一份可回放脚本。交接按 `handoffs/TEMPLATE.md` 附真实命令与输出。

## 调试时按什么顺序查

先确认物理速率，再确认图像格式。`lsusb -t` 中的 5000M 说明主机与相机建立了 SuperSpeed 链路；`v4l2-ctl --list-formats-ext` 说明当前驱动公开了哪些左右模式。接着抓取固定时长的原始帧，统计左右完整帧数、序号跳变、主机队列峰值、每帧实际步幅、左右顺序和曝光控制返回值。带时间戳的日志与原始帧一起保存，便于 B 判断同步、C 重放模型输入。

PCIe 调试从合成图案开始：左图递增数字、右图不同常量，验证左右标识；再把亮点放在四角与边缘，验证 原图到 640×360/400×300、到 256×256 ROI、再到 FPGA 球心的坐标映射。最后切换真实球视频，记录每级输入输出 `pair_id`。队列拥塞时先保留原图和状态计数，再根据处理预算调整显示和调试存盘频率。

交付给评委看的记录应包含一张清楚的数据流图、一段连续运行日志、同图 FPGA/软件候选对照及可回放的异常样例。这样接口和硬件加速的作用都有具体证据。
