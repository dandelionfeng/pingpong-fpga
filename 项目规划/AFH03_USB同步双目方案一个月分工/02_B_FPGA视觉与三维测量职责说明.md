# B 个人分工说明：图像测量、三维轨迹与发球分析

## 第一部分 你要做什么，需要哪些工具

你负责把画面中的球变成可测量的结果。A 提供左右图像和可能有运动的区域，你要从原始图像里找到球的中心，再结合左右视角算出球在空间中的位置，把连续位置整理成轨迹，最后给出离手、最高点和触拍附近的记录，以及抛球高度。

没有相机时，你可以使用公开的成对标定图片和电脑生成的左右图像。先用位置已知的场景检查测量程序，再加入干扰、遮挡和缺帧，观察它能否记录测量质量、重新找到球，以及在信息不足时给出清楚的状态。C 提供手和球拍的位置，并独立复核你的结果；你负责把这些信息与球的运动联系起来。

软件部分使用 C++ 和 OpenCV 编写，便于和 A 的主程序组合，也便于后续迁移到板卡。Python 用来生成测试画面、整理已知位置和绘制结果。Windows 或 Linux 都可进行日常开发，最后要能接入 A 在 PC Linux 上运行的共用程序。

你还负责 FPGA 后半部分的图像处理和输出整理，使用 Verilog 编写逻辑，使用 Icarus Verilog 做仿真，使用 TD 准备目标芯片的工程。你与 A 对接中间图和数据格式，与 C 对接手、球拍位置及测试记录。相机到货后，需要重新测定真实相机的参数，并记录实物测量结果。

## 第二部分 具体实现方法与交付材料

### FPGA 后四级与掩膜输出

独立复核 A 的整数参考，重点检查 Gaussian 取整、同眼帧差、阈值、边缘和首帧状态。使用单点、棋盘、全 0/255 和边缘物体等输入，独立构造预期结果，保留每一级的中间图与差异记录。

实现腐蚀→膨胀→膨胀→腐蚀四级 RTL，使用 3×3 邻域、行缓存和 valid/ready 流控，各级边界沿用 replicate 约定。左右眼独立管理状态，与 A 的前三段流水线连接；仿真覆盖随机停顿、复位、短帧、左右切换及边缘输入。将 640×360 的二值 Mask 按 1 bit 打包，每眼每行 80 字节，每对共 57,600 字节；位序与描述符布局由 A/B 评审后记录版本。

### 从运动区域到原图球心

对搜索图 Mask 做 8 邻域连通域分析，按当前配置筛选候选，并利用已有轨迹确定需要优先测量的区域。候选位置映射回同一 pair_id 的 1280×720 原图，在 256×256 ROI 内测量；保留 ROI 原点、补齐方式和有效范围，输出原图坐标。

在局部 64×64 区域使用 Otsu，检查亮球和暗球的极性，结合闭运算与 moments 计算亚像素球心。记录轮廓完整性、局部边界、遮挡等质量信息及拒收原因；Sobel 局部边缘分析用于观察轮廓并辅助处理部分遮挡。清晰球、边缘球、多运动物体及顶点附近静止球分别保存样例，球心结果明确标出观测、滤波和预测来源。

### 双目标定与三维坐标

使用 OpenCV 成对棋盘样例练习 findChessboardCornersSB、calibrateCamera、stereoCalibrate 和 stereoRectify，完成参数保存与加载。公开图片的方格实际尺寸未知时，只记录方格单位的结果。另用多个棋盘姿态、非零相机姿态和畸变的独立双目合成场景检查几何计算；普通单目图用于二维模块测试。

运行时只对球心使用 undistortPoints，结合 R1/R2 和 P1/P2 得到校正像素，再通过 triangulatePoints 计算齐次点。除以第四分量得到 Xrect，用 Xc=R1ᵀXrect 回到左相机坐标，再用 Xw=Rcwᵀ(Xc−tcw) 变换到世界坐标；Rcw、tcw 表示世界到左相机的变换。沿用 X 为台宽、Y 为台长、Z 向上和米制单位，检查正深度、视差、极线及重投影信息，并记录无效观测原因。

真实相机到货后，按 72°、3.6 mm 双 OV9281 的实际安装和锁焦状态重新标定，基线沿用 150～200 mm 的安装范围。使用实际尺寸的标定板建立尺度，通过 solvePnP 建立世界坐标，并记录已知实物位置的测量。保存内外参、世界变换、图像尺寸、单位和版本。

### 连续轨迹与重新寻找球

使用实际采样时间计算 dt，建立带自由飞行重力的三维 Kalman 跟踪。输入噪声、离群、遮挡、缺帧和时间跳变时，记录轨迹状态和重捕获过程。球到达顶点附近、运动 Mask 暂时为零时，将预测位置反投影到左右图像，用预测 ROI 继续尝试局部测量。

预测点用于寻找球和显示，原始观测、滤波结果及预测值分栏保存。C 提供的手、球拍框按 source_pair_id 对应到来源帧，并保留类别框质量、可见性与模型版本，供后续事件分析使用。

### 离手、最高点与触拍分析

建立持球准备、上抛、顶点、下落和触拍的状态序列。离手结合球与手的分离和连续上行观测，触拍结合球与球拍的接近、轨迹折点及速度变化；用相邻观测给出时间区间，并保存对应图像和轨迹片段。取消发球、缺少手或球拍、严重遮挡等场景输出相应状态，证据不足时记录不可确定。

使用有效实际观测进行带权稳健最小二乘拟合，水平分量采用线性模型，竖直分量采用二次模型，求最高点与抛球高度。拟合依据、事件区间和测量不确定度随结果一起保存；判罚阈值沿用现有评审安排，相关变更由模块负责人评审。

### 独立样例与模块联调

与 C 共同准备合成双目场景，将算法输入和已知球心、三维位置、事件时刻分开保存。你实现测量程序，C 用独立评分程序复核结果，A 负责接入完整回放。记录球心、三维、跟踪和事件各层结果及失败样例，便于判断问题来自图像、几何、语义还是状态处理。

### 需要交付的材料

交付后四级 RTL、Mask 打包模块、testbench、输入与预期结果、中间图、差异日志和波形。附上数据格式说明及已有的目标工程、综合记录和工具版本。

交付球心、标定、三维变换、跟踪与事件处理的 C++ 代码及调用说明，配套配置、标定参数和世界坐标定义。交付合成输入与独立真值生成材料、轨迹和事件导出结果、证据图像、失败样例及复核记录；附上真实相机标定操作说明和已完成的实物测量原始记录。
